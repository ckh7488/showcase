# PortA PCB 전송경로 평가 및 후속 조사 방향

2026-09-08 · Rev. 1 · 제조 Gerber 기반 RX 수동 전송경로 · 100 MHz 평가

## 01. 이번 결과로 내리는 결정

**현재 계산한 PCB 연결 구간의 반사·전달손실은 작은 편으로 판단한다. 이 손실을 더 줄이기 위한 PCB 배선 재설계·재제작은 현재 링크 플랩 대응의 첫 조치로 채택하지 않는다. 다음 조사에서는 케이블 분기부, 실드 접촉, 접지 상태에 따른 잡음 유입과 PCB의 잡음 전달 경로를 우선 확인한다.**

이 결정은 현재 확보한 해석 결과와 사용자 보고를 종합한 공학적 우선순위 판단이다. 제조된 PCB 두 장을 계속 평가 대상으로 사용하면서, 실제 장애를 설명할 가능성이 더 큰 조건부터 비교한다.

| 판단 대상 | 현재 판단 | 이에 따른 행동 |
| --- | --- | --- |
| T2 케이블측 패드부터 M12 PCB 패드까지의 RX 반사·전달손실 | 100 MHz 모델값은 양호한 쪽이다. 큰 전달손실의 증거는 없다. | 선폭·간격·비아를 바꿔 RL 수치만 높이려는 재제작은 후순위로 둔다. |
| 같은 PCB가 외부 잡음을 받아들이는 정도 | 이번 차동 입출력 결과와 별도로 확인할 항목이다. | 실드·기준전위·절연 경계와 공통모드→차동모드 변환을 조사한다. |
| 현장 링크 플랩의 우선 조사 대상 | 설치·배선 조건에 민감한 EMC 경로를 우선한다. | 케이블 분기부와 실드·접지 조건을 하나씩 바꿔 비교한다. |
| PHY 전원·리셋·상태 이상 | 모터가 계속 돈다는 사실만으로 제외할 수 없다. | 링크 다운 시점의 PHY 상태와 전원·리셋 정보를 함께 확보한다. |

여기서 **배선 손실에 대한 판단**과 **제품 전체의 통신 여유**는 구분한다. 이번 결과는 전자에 대해 다음 행동을 정할 근거를 제공한다. PCB 전체의 무결함 선언이나 현장 통신의 보증으로 확대하지 않는다.

## 02. 약 20 dB가 뜻하는 실제 크기

같은 Gerber 형상에 두 가지 격자를 적용한 주파수영역 FEM 결과다. 모두 100 Ω 차동 포트를 사용했으며, 아래 중심 지표는 RX 경로다. 최신 수치는 NGSolve 계산이고, 과거 openEMS 결과를 세 번째 수렴 표본으로 섞지 않았다.

| 지표 · 100 MHz | 기본 격자 | 더 촘촘한 격자 | 해석 |
| --- | --- | --- | --- |
| T2측 RX 반사손실 | 19.74 dB | 20.42 dB | 클수록 반사가 작다. |
| M12측 RX 반사손실 | 19.74 dB | 20.42 dB | 실제 RX 신호가 들어오는 반대쪽도 유사하다. |
| T2 → M12 RX 삽입손실 | 0.0464 dB | 0.0396 dB | 0 dB에 가까울수록 전달 감쇠가 작다. |
| T2측 입사 전력 중 반사 | 1.063% | 0.907% | 약 1%가 입사 포트 쪽으로 돌아간다. |
| 반대쪽 RX 차동 포트로 전달 | 98.937% | 99.092% | 약 99%가 해당 출력 포트에 전달된다. |

반사손실 RL = −20 log₁₀(반사파 진폭 / 입사파 진폭)이다. **20 dB는 반사파 진폭 10%, 반사 전력 1%**에 해당한다. 삽입손실 IL = −20 log₁₀(전달파 진폭 / 입사파 진폭)이며, 여기서는 양쪽 기준 임피던스가 같으므로 전력비는 10^(−IL/10)이다.

**이 계산 조건에서 해당 단일 구간을 완전한 전달 상태로 개선해도, 회복할 전달손실은 약 0.040~0.046 dB다.** 입사 전력 대비 약 0.91~1.06%p의 전달 전력 차이에 해당한다. 따라서 이 구간의 명목 배선 손실 개선만을 첫 대응으로 삼을 기대효과는 작다고 판단한다. 실제 케이블·트랜스와 연결했을 때 생기는 다중 반사까지 이 숫자로 상한을 정한 것은 아니다.

모델은 완전도체와 무손실 유전체를 사용했다. 따라서 이 삽입손실은 주로 반사로 전달되지 못한 양을 나타내며, 실제 구리 저항과 유전체의 흡수 손실을 합산한 값은 아니다. **RL과 IL은 여기서 서로 밀접하게 연결된 수치이므로 독립적인 두 번의 검증으로 세지 않는다.** 또한 반사 전력 1%는 패킷 손실률 1%나 고장 원인 비중 1%를 뜻하지 않는다.

## 03. 어느 PCB 부분에 대한 판단인가

**T2 케이블측 패드 → Control PCB 선로 → Molex 64핀 근사 접점 → Motor PCB 선로 → M12 PCB 패드**가 이번 평가 구간이다. 보드는 두 장을 적층하며, 각각 구리 4층이다. 사용자 확인에 따라 제조본에 더 가까운 Gerber를 형상 기준으로 사용했다.

| 구분 | 이번 모델의 내용 |
| --- | --- |
| 구리·기준면 | 두 보드의 Gerber 구리와 내부 기준면을 포함한다. 신호 두 가닥만 공중에 놓고 계산한 모델이 아니다. |
| 도금홀·GND 연결 | 전체 도금홀 788개를 포함한다. 그중 소스에서 GND로 분류된 비아·부품 도금홀 568개의 입력 포함을 좌표로 확인했다. |
| 보드 적층 | 56 / 110 / 36 / 1130 / 36 / 110 / 56 µm, 합계 1.534 mm. 외층 구리·절연체·내층 구리 순서다. |
| 재료 | FR4 상대유전율 4.5, 무손실 유전체, 완전도체 구리. |
| Molex | Control 714362364 / Motor 714393364. 결합부는 15 mm 길이, 0.205 × 0.30 mm 단면의 직선 접점 64개로 근사했다. 실제 스프링 형상과 LCP 하우징은 제외했다. |
| 전기 포트 | T2 TX, T2 RX, M12 TX, M12 RX의 차동 포트 4개, 각각 100 Ω. RX는 양쪽 입사 방향을 계산했다. |
| 이번 범위 밖 | LAN9354 내부·전원·리셋, T2 내부, 실장 보호소자의 실제 동작, M12 몸체·실제 접점, 외부 20 m 케이블, 실드 접촉 상태, 외부 잡음원. |

| RX 신호 | T2 패드 | Control CON2 패드 | Motor CON2 패드 | Motor CON1 패드 |
| --- | --- | --- | --- | --- |
| RX+ | 11 | 28 | 37 | 6 |
| RX− | 9 | 27 | 38 | 5 |

마지막 열은 M12가 연결되는 **PCB 패드 번호**이며 외부 커넥터의 접점 번호와 구분한다. T2 부품은 HX1260FNLT로 확인되어 있지만, 이번 구간은 그 케이블측 패드에서 시작하므로 트랜스 내부 성능을 평가한 결과가 아니다.

## 04. 수치가 얼마나 안정되었나

두 격자의 결과는 **약 20 dB 부근에 모였으며, 배선 손실이 작다는 판단 방향은 동일하다.** 다만 설정해 둔 엄격한 격자 수렴 목표까지 통과한 상태로 기록하지는 않는다.

| 검증 항목 | 관측값 | 사전에 둔 수치 목표 | 상태 |
| --- | --- | --- | --- |
| RX 주변 국부 격자 크기 | 0.100 → 0.075 mm | 더 촘촘한 공간 분할 비교 | 두 모델 계산 완료 |
| 자유도 | 3,483,013 → 4,903,607 | 동일 형상에서 해상도 증가 | 비교 완료 |
| 반사손실 변화 | 0.687 dB | 0.5 dB 이하 | 목표 미달 |
| 삽입손실 변화 | 0.0068 dB | 0.05 dB 이하 | 목표 충족 |
| 선형 잔차·상호성·수동성·포트 전력 일치 | 각 모델의 설정 기준 통과 | 계산 내부의 일관성 확인 | 통과 |
| 경계·포트 배치 변화, 주파수 전 대역 | 추가 비교 미실시 | 모델 의존성 확인 | 남은 검증 |

0.687 dB의 RL 변화는 반사 전력으로 약 **0.155%p** 차이다. 이것이 이번 의사결정을 뒤집을 만큼 큰 전달손실 차이로 나타나지는 않았다. 두 점은 통계적 신뢰구간이나 실제값의 상·하한은 아니지만, 현재 단계의 조사 우선순위를 정하는 데 활용한다.

문서에서는 **“100 MHz 두 격자 결과는 약 20 dB로 유사하며, 실무상 낮은 손실로 평가한다”**고 표현한다. “전 대역 수렴 완료” 또는 “제품 적합성 통과”로 표현하지 않는다. 남은 검증은 최종 수치 확정이나 원인 후보의 우선순위가 바뀔 때 수행하며, 지금 당장 RL 소수점을 더 맞추는 장시간 계산을 다음 단계의 선행조건으로 삼지 않는다.

근거: [두 격자 비교 기록](records/porta-em/full-fem-first-mesh-comparison.json), [세밀 격자 내부 검증](records/porta-em/runs/full-fem-net-union-100mhz-h075-order0/fem-checks.json).

## 05. 합격 기준과 이번 판단의 관계

**PCB의 어느 구간이든 RL 20 dB 이상이면 통신 합격이라는 공통 기준은 없다.** 20 dB는 이번 경로의 반사 크기를 해석하는 값이다. 통신 불량 경계에서 몇 dB의 여유가 있는지를 직접 측정한 값은 아니다.

참고로 UNH-IOL의 공개 100BASE-TX PMD 시험서 v3.5, 시험 25.2.1은 완성된 수신 입력 인터페이스에 대해 다음 반사손실 조건을 제시한다. 이 시험서는 IEEE 802.3-2005 및 ANSI X3.263을 참조하며, 아래 수치를 최신 규격의 별도 개정 여부까지 인증한 것으로 취급하지 않는다.

| 주파수 | 해당 시험서의 최소 수신 반사손실 |
| --- | --- |
| 2~30 MHz | 16 dB |
| 30~60 MHz | 16 − 20 log₁₀(f / 30) dB · f는 MHz |
| 60~80 MHz | 약 10 dB |

이 시험은 85 Ω 및 115 Ω 조건의 완성된 입력 인터페이스를 다룬다. 현재의 **100 MHz · 100 Ω · PCB 수동 구간** 결과에 위 마스크를 직접 빼서 “규격 대비 10 dB 여유”라고 계산하지 않는다. 시험 대상과 조건이 다르기 때문이다. [UNH-IOL 시험서, 시험 25.2.1](https://www.iol.unh.edu/sites/default/files/testsuites/ethernet/CL25_PMD/PMD_Test_Suite_v3.5.pdf#page=22).

LAN9354 전용 배선 지침은 PHY–트랜스와 트랜스–커넥터 구간 모두 100 Ω 차동 배선을 요구한다. 또한 절연 경계 양쪽의 기준면 처리를 구분한다. 따라서 후속 EMC 검토에서도 GND 구리를 무조건 늘리는 처방보다는, 해당 신호가 절연 경계의 어느 쪽에 있는지부터 확인한다. [Microchip LAN9354 Routing Checklist Rev. A](https://www.microchip.com/content/dam/mchp/documents/UNG/ProductDocuments/BoardDesignFiles/RoutingChecklistforLAN9354SQFNRevA.pdf).

## 06. 다음 조사의 우선순위

현장에서 더 자주 발생한다는 보고, 20~40 cm 분기부에서 네 선을 한꺼번에 꼰 구조, 불확실한 실드 접촉, 크레인마다 다른 접지 상태를 함께 고려하면 **설치·배선 조건에 따라 달라지는 잡음 결합을 먼저 비교하는 편이 정보 가치가 높다.** 이것은 현재 정보에 따른 가설 우선순위이며, 이미 입증된 고장 원인 순위나 확률은 아니다.

| 순서 | 확인 대상 | 선택 이유 | 다음 결과로 얻을 결정 |
| --- | --- | --- | --- |
| 1 | 20~40 cm Ethernet 분기부와 실드 접촉 | 사용자 확인상 쌍별 꼬임이 유지되지 않고, 접촉이 끊기는 경우도 있다. | 같은 잡음 조건에서 정상 쌍꼬임·연속 실드 대비 얼마나 악화되는지 비교해 배선 개선 순서를 정한다. |
| 2 | 센서 몸체·실드·제어반·PC·SMPS의 실제 기준전위 경로 | 현장별 접지 상태가 다르고 PC·몸체가 부유할 수 있다. | 어떤 연결 상태가 수신측 잡음을 크게 만드는지 정리하고 설치 조건을 표준화할 근거를 만든다. |
| 3 | PCB 절연 경계·트랜스 주변·보호회로·전원 경로 | 낮은 차동 전달손실과 잡음 내성은 별도 특성이다. | 동일한 외부 잡음이 PCB 안에서 신호나 PHY 전원으로 넘어오는 경로를 찾는다. |
| 4 | 명목 차동 선로의 임피던스·배선 형상 재설계 | 현재 모델에서는 개선할 전달손실이 작다. | 새로운 증거가 나오면 재평가한다. 지금은 첫 재제작 사유로 삼지 않는다. |

TI의 산업용 Ethernet EMC 자료도 잡음 주입 시 링크 손실, 공통모드 전류 경로, 접지 전위 변동 및 모드 변환을 함께 다룬다. 이 자료는 위 조사 방향을 뒷받침하지만, 현재 제품의 EMC 원인을 확정하는 측정 결과는 아니다. [TI SNLA466A, EMC Immunity Test](https://www.ti.com/lit/an/snla466/snla466.pdf).

사용자 보고상 시험실에서도 약 2~3일에 한 번, 약 10분간 문제가 생길 수 있다. 따라서 “현장에만 있는 외부 장비”로 원인을 한정하지 않는다. 시험실의 모터·SMPS·접촉 변화·PHY 전원 및 상태 이상도 남겨 둔다. 모터가 계속 회전하는 현상은 전체 전원 상실 가능성을 낮추지만 PHY 국부 이상을 배제하지 않는다.

## 07. 다음 한 스텝의 구체적인 설계

**다음 질문은 “신호가 얼마나 잘 지나가는가”에서 “같은 외부 잡음이 어느 조건에서 RX 차동 잡음으로 가장 많이 바뀌는가”로 옮긴다.** 첫 비교는 분기부 쌍꼬임과 실드 접촉의 영향에 한정한다. 이 문서는 그 비교를 제안하며, 아직 실행된 결과로 기재하지 않는다.

| 비교 축 | 대조할 조건 | 고정할 조건 |
| --- | --- | --- |
| 분기부 배선 | 현재 네 선 일괄 꼬임 / 두 차동 쌍을 각각 꼰 상태 | 도체 규격, 전체 길이, 주변 구조, 종단 |
| 노출 길이 | 20 / 30 / 40 cm | 각 길이에서 두 배선 방식의 나머지 조건 |
| 실드 접촉 | 연속 접촉 / 접촉 임피던스 증가 / 개방 | 잡음 주입 위치·소스 임피던스·주파수 |
| 접지 상태 | 실제 확인된 현장별 연결 구성을 별도 사례로 기록 | 의도하지 않은 PE·출력 음극·신호 GND의 임의 결합을 피하고, 구성 자체를 명시 |

첫 단계의 핵심 출력은 **입력 공통모드 잡음 1 V당 RX에 발생하는 차동 잡음(mV/V)**과 주파수별 변화다. 1 V는 비교용 정규화 값이며 실제 현장 잡음이나 인증 시험 레벨을 가정한 값이 아니다. 두 도체가 함께 흔들리는 잡음이 두 도체 사이 전압 차이로 바뀌는 정도를 수치화한다.

정확한 케이블 단면, 꼬임 간격, 실드 전달 임피던스와 접촉 R/L이 문서나 측정으로 확인되면 그 값을 사용한다. 확인되지 않은 항목은 범위로 바꾸어 비교하고, 실제 구조에서 확정된 값과 가정값을 표에 나눈다. 처음부터 20 m 전체를 극세 격자로 계산하지 않고, 분기부·접촉부의 국부 모델과 긴 케이블의 전송선 모델을 연결하는 방법부터 검토한다.

비교 모델에서는 입력 잡음 조건과 종단을 고정한 채 한 요소씩 변경한다. 가장 효과가 큰 변경 후보는 여러 주파수와 가정 범위에서도 개선 방향이 유지되는지 확인한다. 차이가 수치 변화량과 비슷하면 해당 두 조건을 동순위로 남긴다. **모든 원인의 기여율 합계를 억지로 100%로 맞추지 않는다.** 실드와 배선 불균형은 서로 영향을 줄 수 있기 때문이다.

실물 비교 단계에서는 PortA 심볼 오류의 시간당 증가량, 링크 다운 횟수·지속 시간, PHY 상태·리셋·전원 정보를 같은 시간축에 기록한다. 현재 발생 간격을 고려하면 하루 무고장만으로 개선 성공을 선언하지 않고, 기존 발생 간격을 여러 번 포함하는 관측이나 동일 조건의 반복 자극에서 전후 차이를 확인한다. 수동 모델의 mV/V만으로 LAN9354가 반드시 끊기는 전압을 만들어내지는 않는다.

## 08. 언제 PCB 배선 판단을 다시 열 것인가

| 새로 확보된 증거 | 바뀌는 조사 방향 |
| --- | --- |
| 관련 주파수 대역의 추가 해석이나 실측에서 현재 단일 주파수 결과가 놓친 큰 반사·전달 저하가 나타남 | 대역별 RL·IL과 TDR 등을 통해 위치를 좁히고 배선 형상을 재평가한다. |
| 실제 Molex·M12·트랜스·보호소자를 포함하자 결과가 유의하게 악화됨 | 해당 접점·부품·패드 주변을 분리 비교하고 필요한 실장/PCB 변경을 정한다. |
| 동일 케이블·접지·잡음 조건에서 PCB 또는 특정 구간 교체가 오류·링크 플랩을 반복적으로 줄임 | PCB 원인 후보의 우선순위를 올리고 변경 구간을 좁힌다. |
| 공통모드 입력에 대한 차동 잡음 또는 PHY 전원 변동이 특정 PCB 구조에서 커짐 | 배선의 명목 RL을 높이는 작업과 구분해, EMC 경로를 개선하는 PCB 변경을 검토한다. |

이 문서가 정하는 것은 **조사 순서와 설계 변경의 판단 근거**다. 우선 현재 PCB를 유지한 채 분기부·실드·기준전위 조건의 영향을 수치 비교하고, 그 결과에 따라 다음 수정 대상을 정한다.
