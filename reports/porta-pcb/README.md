# PALA720 · PortA 통신 경로 분석

이 폴더가 공개 보고서의 유지보수 원본입니다. 기존 Three.js 기구도, PCB 구간 전환, TX/RX 선택, 회전·확대 기능을 보존합니다.

현재 본문은 완료된 가장 정밀한 h075 local-p1 계산의 100 MHz TX 28.611 dB / RX 26.188 dB를 사용합니다. 내부 16 dB 목표는 상회하지만 마지막 성공한 격자 비교의 최대 변화 0.758 dB는 수치 목표 0.5 dB에 미달합니다. `fully_converged=false`와 수치 비교의 `false`를 유지하며, 추가 h060 해석기의 오류 및 30분 상한 중단을 완료된 결과로 표시하지 않습니다.

## 수치 갱신 규칙

- 본문은 트랜스 케이블측 패드 ↔ 두 PCB와 근사 64핀 접점 ↔ M12 PCB 패드의 **TX/RX 정밀 결과 두 행**과 T2 ↔ PHY의 **TX/RX 초기 결과 두 행**, 총 네 행을 보여줍니다. 서로 다른 RX 격자 두 개를 TX/RX 비교처럼 배열하지 않습니다.
- 현재 결과는 `report-data.json`의 `precision_recheck_20260911`과 `records/tx-recheck/summary.json`을 기준으로 합니다. 이전 `base`, `fine`, `phy_side_initial_openems`는 보존된 과거 기록입니다.
- 실제 계산한 100 MHz 값만 표시합니다. 2–100 MHz의 내부 목표선과 한 주파수의 계산 결과를 전 대역 통과로 혼동하지 않습니다.
- PHY측 초기 openEMS RL은 본문과 3D 바로 아래에 TX 30.8366 / RX 29.1804 dB로 표시합니다. 항상 초기·수렴 미검증 표시를 붙입니다. IL/전달률은 남은 비물리적 수치 오차 때문에 본문에서 정밀값 미확정으로 표기하고, `records/phy-initial-summary.json` 및 접힌 원시값 표에서 실제 계산값을 보존합니다. PHY 결과를 제거하거나 케이블측 수치로 대신하지 않습니다.
- 격자 세밀화 및 국부 고차 전계 표현 비교는 **동일 제조 Gerber 모델의 계산 정확도 확인**입니다. PCB를 수정·재제작해 성능이 개선됐다고 서술하지 않습니다.
- 본문의 반사손실, 삽입손실, 목표 대비 여유와 반사 전력은 같은 선택 결과에서 가져옵니다. 누락된 값에 0이나 다른 경로의 값을 넣지 않습니다.
- 두 격자의 수치 검증 목표와 16 dB PCB 설계 목표를 구분합니다. 계산한 범위 밖의 PHY 내부·마그네틱·외부 케이블·EMC 내성을 통과했다고 확대하지 않습니다.

`detailed.html`과 `assessment.md`는 RX 중심의 초기 판단 기록입니다. 상단 정정 안내와 현재 보고서 링크를 유지합니다. 공개 파일을 과거 생성 스크립트로 덮어쓸 때는 최신 TX/RX 수치와 검증 범위가 사라지지 않는지 먼저 확인합니다.

갱신 후 저장소 루트의 `scripts/validate.py`와 실제 브라우저에서 수치 선택, 3D 연동, 출처 링크 및 모바일 화면을 확인합니다.

## 표시와 기록 검토 규칙

- 네 경로 모두 결과와 3D가 양방향으로 동기화됩니다. 3D 아래에는 현재 구간의 TX/RX 값을 함께 표시합니다. 전체 표시에서는 같은 구간의 직전 선택쌍을 상세값으로 유지하고 이를 안내합니다. 다른 구간의 숫자를 남겨두지 않습니다.
- `ground-vias.js`의 선택쌍별 마스크는 Gerber 신호 구리와 GND 비아 중심의 XY 거리 3 mm로 만든 표시 필터입니다. 전체 선택은 TX/RX 합집합이며, 실제 리턴 전류 분포나 EMC 검증으로 해석하지 않습니다.
- 과거 해석 페이지의 상단과 케이블측 `#results` 진입점에 초기 기록 안내 및 최신 보고서 링크를 유지합니다. 과거의 실행 상태를 현재 작업 상태로 소개하지 않습니다.
- 원본 검사 JSON 두 개는 SHA-256 재현을 위해 `.gitattributes`에서 `-text`로 보존합니다. JSON 내용이 같더라도 줄바꿈을 정규화해 원본 바이트 해시를 깨뜨리지 않습니다.

## 경로 차이 해석

- `records/path-comparison.json`은 원본 제조 배선의 TX/RX 길이·via와 공개 NPZ의 차이를 비교한 근거입니다. 최근 개선 설계의 결과로 혼용하지 않습니다.
- 100 MHz RL 차이 2.423 dB는 반사 전력 0.138% / 0.241%의 차이이며 추가 전달손실 2.423 dB가 아닙니다.
- RX의 평균 경로는 길고 Motor에서 각 선이 한 번 층을 전환하지만, 두 보드 합산 |P−N|은 RX가 오히려 작습니다. 총 skew만으로 RL 순위를 설명하지 않습니다.
- 경로·층 전환·팬아웃·시험 포트의 기여를 분리 계산하지 않았으므로 개별 원인의 dB 또는 고장 기여율을 만들어 쓰지 않습니다. 실제 저항/TVS 부하와 PHY·트랜스 내부는 이 모델에 없습니다.
- 로컬 수치 바인더 `update_precise_report.py`는 `render_path_analysis.py`와 두 근거 JSON을 사용합니다. 수치 갱신 때 네 결과, 검증 수준, 마지막 현상 분석을 함께 보존합니다.
