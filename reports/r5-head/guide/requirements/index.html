R5 인수 기준 (2층 동작·검증 스펙)

1층 사용자 요구사항, 2층 고정 검사 조건과 장면 수치 기준을 B25의 CAD, 펌웨어와 실물에 적용합니다. 하드웨어 없이 모형을 확인하고, A5 첫 통전과 한 축 구동을 거쳐 P01–P08을 기록합니다. 제어 설정 · 실물 시험

B25 인수 검사

저장소 루트에서 Python 3.11 이상으로 실행합니다.

python spec/verify.py --revision B25
python spec/verify.py --b25-physical

--revision B25는 S01–S06(S01b 포함), C01–C04, M01–M09와 P01–P08을 표시합니다. --b25-physical은 P06과 P07의 JSON만 골라 보여 줍니다. 종료값은 전부 통과하면 0, FAIL이 하나라도 있으면 1, FAIL 없이 UNVERIFIED가 있으면 2입니다.

  • S01과 S01b의 자동 결과는 추적 모형 판정입니다. S02·S03·S04에는 각각 P05·P03·P06 실물 기록도 필요합니다.
  • S05는 C01–C04와 P01·P08을 함께 봅니다. B25 검사기는 현재 C01–C04와 S06을 UNVERIFIED로 표시합니다. 전체 조립·가동·체결 증거는 현장과 CAD에서 별도로 판정합니다. B25 판정 구현 · 검토와 판정
  • M과 P는 선택한 CAD의 리비전과 SHA-256에 맞는 기록을 읽습니다. 실제 계측과 현장 판정은 시험자가 기록합니다. 기록 형식과 검사 범위

python spec/verify.py --revision B22 또는 옵션 없는 실행은 보관된 B22를 검사합니다. B24 디지털 자료의 재현 절차는 해당 리비전에 있습니다. B24 검사 재현

동작 장면

ID 합격 기준
S01 정면으로 대기하다가 1.5 m 앞을 0.8 m/s로 지나가는 사람을 눈과 목으로 따라봅니다.
S01b 옆 40°의 사람에게 고개를 돌릴 때 목이 목표를 12° 넘게 지나치지 않고, 정지 후 시선 오차가 10° 이하입니다.
S02 받침을 수평으로 놓고 로봇 눈을 바닥에서 1.4 m에 맞춥니다. 앞 1 m에 선 눈 높이 1.6 m인 사람을 볼 수 있는지 실제 동공 방향과 P05로 확인합니다.
S03 깜빡임 한 번은 0.8~1.5초이고 시작 간격은 4~10초입니다. 눈꺼풀이 50회 연속 걸림 없이 움직이는지 P03에서 봅니다.
S04 목이 중립일 때 62틱에서 턱 끝이 눈에 보이게 내려가는지 B25 P06에서 확인하고 하강량을 기록합니다. Goal PWM으로 제한된 저하중 직결 턱의 열림 쪽 스토퍼 여유는 1° 이상입니다. 소리는 선택입니다. 추적 중 간헐적인 턱 구동은 별도 검증 후 사용합니다. 턱 판정 조건
S05 정해진 순서와 공구로 끝까지 조립하고, 뒤쪽 케이블 덮개와 하부 보드 덮개의 나사를 전부 빼도 너트가 남습니다. C01~C04, P01 및 P08을 확인합니다.
S06 M3 원통머리, 일반 육각너트와 평와셔를 기본으로 합니다. 구매품 나사산·홀과 핀 이탈 방지용 무두나사는 명시된 위치에서 예외로 둡니다. 판정은 본체를 기준으로 합니다.

S01은 아래 조건을 모두 확인합니다.

  • 대상이 카메라 시야에 처음 들어온 프레임부터 1초 이내에 시선 오차가 10° 이하로 들어옵니다.
  • 시선이 처음 10° 이내에 들어온 순간부터 대상이 반대쪽 80°에 닿을 때까지 평가합니다. 시야에서 벗어나는 구간도 평가 시간에 포함하며, 전체의 85% 이상에서 시선 오차가 10° 이하입니다.
  • 추적 중 목 속도는 초당 45° 이하입니다. 얼굴을 놓치면 마지막으로 보던 방향을 2~3초 응시한 뒤 초당 15° 이하로 정면에 돌아옵니다. 새 얼굴이 보이면 눈이 먼저 그쪽으로 움직이고, 목이 이어서 따라갑니다.

추적 모델은 PC 제어와 펌웨어의 구동 설정을 사용합니다. 수평 화각 106°와 영상 지연 120 ms는 모형의 가정값입니다. S01b는 수평 시선 오차를 검사합니다. 설치한 렌즈, 지연과 실제 추적은 B25 실물 시험에서 확인합니다.
