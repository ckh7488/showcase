기록 B25에서 측정하고 기록할 내용
P01 끼움 기본 보정 치수로 출력한 부품에 실제 핀·축·베어링을 건식으로 맞춥니다. 홀과 축의 가공 전후 치수, 시임·고정제, 최종 간극을 기록합니다. 조립과 경화 후 입력을 고정하고 출력의 양방향 반전 유격을 잽니다. 눈 시선 3° 이하, 눈꺼풀 끝 1.5 mm 이하, 턱 끝 1.0 mm 이하, 목 1.5° 이하를 적용합니다. 1·2·7절 · 출력과 맞춤
P02 케이블 전원을 끄고 받침을 고정합니다. 외부 전원·USB를 실제 위치에 연결하고 피복과 고정면에 기준선을 표시합니다. 케이블을 직선과 45°에서 각각 10 N으로 30초 당겨 케이블별 이동량 0.5 mm 이하와 피복 손상을 확인합니다. 최종 카메라·모터 배선은 최대 동작에서 길이 여유 10% 이상, 가동부 간극 1 mm 이상을 확인합니다. 실측 외경의 6배 이상을 고굴곡·실리콘 선에, 10배 이상을 일반 선에 적용하고 제조사 지정 최소 굽힘 반경도 지킵니다. 11·12절
P03 눈꺼풀 보정한 뒤 눈꺼풀 단독 구동을 촬영합니다. 50회 이상 연속 구동에서 걸림 0회, 깜빡임 0.8~1.5초, 시작 간격 4~10초를 확인하고 ID3 단자 최저 전압을 잽니다. 시간 계측에는 개폐량을 0°~90°로 환산하여 닫힐 때 5°를 지난 시점부터 다시 열려 5°를 지날 때까지를 사용합니다. S03 · M07
P04 목 머리를 받치고 토크를 끈 상태에서 ID4·ID5 각각의 보정 중립, 소프트웨어 끝점, 손으로 움직였을 때의 첫 접촉각을 기록합니다. 각 방향 첫 접촉과 설정 끝점의 각도 차에서 **8틱(0.703125°)**을 빼고 2° 이상인지 확인합니다. 구동에서는 무접촉 움직임과 반전 유격, 끝점 떨림을 관찰합니다. 2·3·6·7절 · 목 스토퍼와 보정
P05 시선 받침을 수평으로 놓고 중립 동공 중심을 바닥에서 1.4 m에 둡니다. 수평으로 1.0 m 앞의 1.6 m 눈높이로 보게 한 뒤, 옆 영상의 실제 동공 방향과 카메라 시야를 기록합니다. 추적 시선과 목 움직임은 아래 S01·S01b에서 확인합니다. S02
P06 턱 토크를 끄고 같은 닫힘 보정 영점에서 양방향으로 접촉 없이 움직일 수 있는 마지막 틱을 읽습니다. 닫힘 쪽은 28틱 이상, 열림 쪽은 Goal PWM 제한을 확인했으면 79틱 이상, 확인 근거가 없으면 90틱 이상입니다. 각 방향 피드백 5틱을 포함합니다. 목을 중립에 받치고 턱 시험 모드에서 62틱을 명령합니다. 옆에서 턱 끝이 눈에 보이게 내려가는지 확인하고 닫힘부터 수직 하강량을 mm로 잽니다. 치아 간극, 반전 유격과 모듈 이탈도 기록합니다. 2·3·6·7절 · 턱 시험 모드
P07 카메라·전원과 제어 최종 경로로 조립한 상태에서 목 좌우 한쪽 보정 끝에서 반대쪽 보정 끝을 거쳐 돌아오는 동작을 100회 연속 수행합니다. 양쪽 실제 각도와 ID4 보정 틱, 완료 횟수, USB 끊김·재인식을 기록합니다. 끊김과 재인식 0회, 종료 후 정상 인식이 기준입니다. 장기 전시 전에는 1,000회를 권장합니다. 아래의 카메라 지연, 모터 부하 전압과 재시작 후 토크 해제도 기록합니다. 12·14절 · 전원 실물 검수
P08 전체 조립 B25 절차대로 실제 부품과 배선을 한 번에 조립합니다. 앞 단계를 다시 풀어야 하는 곳이 있는지, 표준 공구가 닿는지, 커넥터가 안착하고 케이블이 눌리지 않는지 확인합니다. 두 어댑터와 USB를 분리하고 뒤 케이블 덮개와 하부 보드 덮개의 나사를 모두 뺀 뒤 포획 너트와 인서트가 남는지 확인합니다. 사용 공구, 걸린 단계와 절차에 없던 추가 가공을 기록합니다. 아래 턱 받침과 5 N 검사를 포함합니다. 3·10·13절 · B25 조립

P02 내부 J2 잠금쇠

두 어댑터·USB·F1·F2를 분리하고 하부 덮개를 받칩니다. 잠금쇠가 결합된 J2 플러그의 뒤턱을 실제로 잡는지 확인합니다. 플러그 몸체를 분리 방향으로 기존 케이블 검사와 같은 10 N으로 30초 당겨 이동량을 기록합니다. 뒤턱 빠짐, 체결품 풀림, 손상이 없고 전원 입력 도통이 유지되어야 합니다. 무전원 도통 순서

P03 눈꺼풀 단독 구동

보정과 한 축 확인을 마치고 목과 턱을 받칩니다. 얼굴이 계속 검출되도록 카메라 앞에 둔 채 실행합니다. 영상에서 눈꺼풀이 닫히고 다시 열린 완전한 50회 이상을 연속으로 확인합니다. 얼굴 소실이나 구동 중단이 있으면 연속 구간을 다시 셉니다. 연속 구동에서 걸림이 0회이고, 각 깜빡임이 0.8~1.5초, 시작 간격이 4~10초일 때 합격으로 기록합니다. 종료 후 목과 턱을 받친 채 토크 해제를 확인합니다. 해제 절차

python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive --axes blink --immediate-hold

P04·P05 전시 추적

전시 추적에서 목을 정면에 두고 앞 1.5 m 선을 0.8 m/s로 양방향에서 지나갑니다. 대상 방향과 눈·목 움직임을 같은 시각 기준으로 기록합니다. 첫 가시 프레임부터 시선 오차 10° 이내까지 1초 이하, 포착부터 반대쪽 80°까지 85% 이상의 시간 동안 시선 오차 10° 이하, 추적 중 목 합성 각속도 45°/s 이하를 확인합니다. 미검출 구간도 평가 시간에 포함합니다. 정지한 추적 자세에서 얼굴을 가려 마지막 시선을 2~3초 유지한 뒤 15°/s 이하로 정면에 복귀하는지 확인합니다. 유지 중과 복귀 중에 새 얼굴을 보여 주고 눈이 목보다 먼저 새 방향으로 움직이는지 촬영합니다. 전시 추적 명령 · S01 판정

S01b는 정면에서 양쪽 40° 대상을 향할 때 목의 넘침 12° 이하와 정지 후 수평 시선 오차 10° 이하를 확인합니다. S01·S01b는 수치와 시험자 판정을 P04·P05 계측 근거에 함께 남깁니다. 검사기의 S01·S01b 행은 추적 모형 결과를 표시합니다. 인수 검사 범위

P06 턱 구동과 복구

표의 스토퍼 여유를 확보한 뒤 실측한 보정표에서 ID6의 abs(high - zero)가 62틱인지 확인합니다. 목을 중립에 받치고 턱 시험 모드를 실행합니다. 두 번째 열림에서 닫힘 자세 대비 턱 끝의 수직 하강량을 잽니다. jaw_stop_reserve_deg는 (열림 쪽 마지막 무접촉 틱 - 62 - 5) × 360 / 4096입니다. 턱 시험 모드에서 펌웨어는 ID6 Goal PWM을 160으로 쓰고 다시 읽어 확인한 뒤 토크를 켭니다. 시험에 사용한 펌웨어와 정상 구동을 근거로 남깁니다. B25 CAD의 하강량은 5.176 mm입니다. 제어와 보정 · 기록 필드 · 턱 CAD 검사

python control/pc/jaw_clack.py --serial /dev/ttyACM0 --drive
python control/pc/commission.py --serial /dev/ttyACM0 --release

전시 턱의 닫힘 복구를 확인할 때는 목과 턱을 받치고 토크를 해제합니다. 목 양축을 중립 ±11틱에 두고, 실측으로 확인한 무접촉 구간에서 턱을 닫힘 영점보다 12틱 넘게 엽니다(예: 확인된 범위 안의 31틱). 110틱은 펌웨어 복구 입력의 상한입니다. 모터 전원이 공급되고 토크 OFF인 상태에서 115200 bps 시리얼로 READ 6으로 시작 틱을 기록하고 ARM_EXHIBIT를 보냅니다. 2.4초 이내 ARMED_EXHIBIT 31 응답을 받고 EXHIBIT_JAW_UNCALIBRATED가 없는지 확인합니다. 응답 뒤 CHECK 6으로 보정 여부, torque=1, 닫힘 영점 기준 −5~+12틱 위치를 기록합니다. 복구 중에는 HOLD와 RELEASE로 중단할 수 있습니다. 시험이 끝나면 목과 턱을 받쳐 RELEASE와 RELEASED를 확인합니다. 전시 턱 복구

P07 카메라 왕복과 전원

P04 보정과 목 좌우 단독 구동을 마칩니다. 외장과 덮개를 닫고 전시에 사용할 PC·USB 연장선으로 연결합니다. 전시 해상도·프레임률로 UVC 영상을 연속 수신하면서 USB 접속 이벤트를 기록합니다. 시험 전후 Windows에서는 USBView의 High-Speed, Linux에서는 lsusb -t의 480M을 확인합니다. 카메라 접합과 조립 전 확인

  1. 추적 프로그램을 닫고 목과 턱을 받쳐 토크를 해제합니다. 자동 반복 송신이 가능한 시리얼 도구를 115200 bps, 줄바꿈 사용으로 엽니다. PING → R5B1 1, ARM 8 → ARMED 8을 확인합니다.
  2. GO 0 0 0 -60 0과 GO 0 0 0 60 0은 ID4의 양쪽 보정 끝점입니다. 각 끝점까지 같은 GO를 약 100 ms마다 보냅니다. 송신 사이에 READ 4로 현재 위치를 읽습니다. RAW 4가 해당 보정 끝 틱의 8틱 이내에 들면 반대쪽으로 전환합니다. 400 ms 동안 GO가 없으면 현재 위치를 유지합니다.
  3. 한쪽 → 반대쪽 → 원래 쪽을 완료해야 한 번입니다. 실제 끝점은 중립과 원시 틱의 차를 360 / 4096으로 환산해 왼쪽은 음수, 오른쪽은 양수로 기록합니다.
  4. 반복 송신을 끄고 HOLD를 보냅니다. 목과 턱을 받친 채 RELEASE → RELEASED를 확인합니다. 보정과 한 축 구동 · 카메라 접합

왕복과 별도로 눈·목 추적과 깜빡임을 전시 설정에서, 턱 동작을 별도 시연 모드에서 확인합니다. 모터 기동·반전이 일어나는 동안에도 UVC 영상을 수신하며 영상 멈춤·프레임 손실, USB 끊김·재인식의 시각을 구동 기록과 함께 남깁니다. 구동 중 두 어댑터와 모터 단자의 최저·최고 전압을 기록합니다. 목 반복 구동 직후 전원을 분리하고 12 V SERVICE 커넥터 두 접합의 절연 표면 온도와 실내 온도를 기록합니다. 구동 중 전원 확인 · 전시 추적과 턱 시험

전시 카메라 지연은 좌우 10°에 표시한 얼굴 이미지의 전환과 로봇 눈의 새 움직임을 같은 고속 영상으로 찍어 프레임 차이를 촬영 프레임률로 나눕니다. 눈이 멈춘 뒤 다음 전환을 반복하고, 카메라 해상도, 실측 프레임률과 지연 중앙값·최댓값을 기록합니다. 모형 입력 지연 camera_latency_s를 다시 잴 때는 얼굴 위치 변화에서 Planner가 새 관측을 받기까지 잽니다. 추적 모형

OpenRB 재시작 시험은 모터 전원을 켠 채 진행합니다. 아래 commission.py 명령은 저장소 루트에서 python control/pc/commission.py --serial /dev/ttyACM0 뒤에 붙여 실행합니다. 포트는 실제 장치에 맞춥니다. 펌웨어 재시작 시험

  1. 목과 턱을 받칩니다. 확인을 마친 단독 구동 모드에서 토크를 켠 뒤 구동 프로그램을 닫거나 시리얼에서 HOLD를 보내고 포트를 비웁니다. --check로 재시작 전 ID 1–6의 torque=를 기록해 시험한 축의 토크가 1인지 확인합니다.
  2. OpenRB만 재시작합니다. 새 구동이나 해제 명령 전에 --check로 torque=를 다시 기록합니다. torque=1인 축은 CHECK로 표시되며 명령의 종료값이 1일 수 있습니다. 응답이 없는 축은 미확인으로 기록합니다.
  3. 목과 턱을 받친 채 --release를 실행합니다. RELEASED와 후속 --check의 전 축 torque=0을 확인합니다. 서보 전원 재투입 시의 시작 상태는 별도로 모터 전원을 껐다 켜고 새 구동이나 해제 명령 전에 확인합니다. 제어 오류와 해제

B24 전시 턱의 냉간 복구 검사 절차입니다. 위치 P 게인은 1000입니다. 전원을 분리하고 목을 중립에서 양쪽 최대 11틱에 받친 뒤, 턱을 검증된 열린 범위 안에서 최대 110틱까지 준비합니다. USB 시리얼에서 ARM_EXHIBIT를 보내고 시간 기록이 있는 응답을 저장합니다. ARM_EXHIBIT 발행부터 ARMED_EXHIBIT 31까지 걸린 시간과 ID6의 위치를 기록합니다. 응답이 없거나 복구가 2.4초를 넘으면 실패입니다. EXHIBIT_JAW_UNCALIBRATED 없이 ID6 보정과 토크가 모두 켜져 있어야 복구 성공으로 기록합니다. 복구 중 위치는 따로 동기화한 위치 계측으로 기록합니다. 복구 도중에는 HOLD와 RELEASE가 즉시 중단을 요청합니다. USB 출력은 복구 결과에서 재개하므로 CHECK 6은 결과가 나간 뒤에 보냅니다. 기한 시험은 USB 호스트의 읽기가 멈춘 경우에도 반복하고, ID6의 첫 토크 OFF 패킷과 실제 해제 확인 시각을 각각 기록합니다. 조립된 모터 단자의 최소 부하 전압 조건을 포함해 반복합니다. 목표값은 보정 영점 이내여야 하며 실제 치아 간격은 닫힘 중에도 0.5 mm 이상이어야 합니다.

목을 받친 뒤 RELEASE의 결과를 확인하고 포트를 닫습니다. 그다음 python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive로 전시 추적 중 턱을 영상으로 기록합니다. 보정 영점 대비 정지 위치와 지속 떨림 여부, 시험 시간과 시험 전후 모터 온도를 남깁니다.

P07 카메라 지연 실측

보정 후 실제 전시용 카메라와 전체 축 설정으로 구동합니다. 카메라 중심에서 왼쪽 10°와 오른쪽 10°에 같은 얼굴 이미지를 번갈아 표시합니다. 화면과 로봇 눈을 한 영상에 240 fps로 찍습니다. 매번 눈이 멈춘 뒤 화면을 바꿉니다. 화면이 바뀐 프레임과 새 방향의 움직임이 두 프레임 연속 보이기 시작한 첫 프레임의 번호 차이를 240으로 나눕니다. 카메라 해상도와 실제 프레임률, 10회 지연의 중앙값과 최댓값을 기록합니다.
