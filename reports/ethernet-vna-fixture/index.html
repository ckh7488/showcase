01 · 접속 구성

어떤 커넥터를 연결하나요?

여기서 선택하는 암·수는 지그에 실장하는 커넥터입니다. DUT 쪽은 맞물리는 반대 성별이어야 합니다. 현재 어댑터는 사내 전용 핀맵이며 범용 M12 Ethernet 결선이 아닙니다.

2공통 발룬 PCB

6미사용 SMA의 50 Ω 로드

2선택 구성의 어댑터 PCB

무전압 수동 DUT용입니다. 24 V 전원과 활성 Ethernet 장비를 분리하고 잔류 전압을 확인한 다음 연결합니다. 전원 핀이 NC인 것만으로 통전 중 사용이 허용되지는 않습니다.

두 기준면과 고정해야 할 부분

LibreVNA의 첫 full 2-port SOLT는 두 SMA 케이블 끝의 50 Ω 기준면을 만듭니다. 그 상태에서 DUT 접속면의 표준을 취득하고 Python UnknownThru 보정을 적용하면, 모델 조건 아래 두 DUT 접속면 사이의 100 Ω 유효 차동 2포트 결과를 얻습니다.

공통 PCB·패치 케이블·어댑터·미사용 로드·CT/shield 상태는 표준과 DUT 측정 사이에 고정합니다. 커넥터 자체를 평가하려면 그 체결부가 DUT 기준면 안에 포함되도록 시험편을 구성해야 합니다.

보드와 신호를 골라 확인하세요

저장된 KiCad 좌표에서 읽은 선로와 패드 중심입니다. 청록 F.Cu · 주황 B.Cu. 원은 패드 위치 표시이며 실제 패드 외형이 아닙니다. 내부 면·커넥터 몸체·3D 간섭·RF 응답은 이 그림에 포함하지 않습니다.

04 · 조립과 첫 확인

공통 보드 두 장을 한 쌍으로 관리합니다

  1. PCB·부품 리비전 확인

    공통 B-SMA1, LLC B-RF1, 암 B-TE1과 해당 Molex 보드를 구분합니다. 핀 번호·부품 성별·DUT mating을 확인합니다. 4종 PCB를 각각 5장 준비하는 구매 기록과 이번 구성에서 실제 조립할 장수는 다릅니다.

  2. 공통 보드에 발룬과 커넥터 실장

    한 장마다 ADT2-1T+ 4개, Samtec SMA 4개, RJ45 1개를 사용합니다. SMA는 F면, 입구는 보드 바깥쪽입니다. 트랜스의 dot/핀 방향을 확인하고 각 SMA 중심–트랜스–RJ45 연결을 검사합니다.

  3. CT·shield 상태를 표시

    기본은 CT-FLOAT: 두 보드의 RCT1–RCT4를 모두 DNP로 둡니다. RSH1은 기준 Port 1 쪽 보드만 납땜 브리지, 반대쪽은 DNP로 관리합니다. CSH1은 기본 DNP입니다. 패치 실드·패널이 만드는 추가 접지 경로도 기록합니다.

  4. 어댑터를 조립하고 체결 하중 지지

    M12는 실제 key·pin 1과 패널/브래킷을 확인합니다. 나사 체결 토크를 신호 핀 납땜부에 맡기지 않습니다. TE 암의 PCB 간격 약 3 mm는 외부 기구로 정하며 핀 어깨를 자동 스토퍼로 보지 않습니다. Molex는 1.25 mm SMT의 브리지·방향을 확대 확인합니다.

  5. DUT 연결 전에 도통·절연 확인

    각 신호선과 NC, shield 경계를 검사합니다. LLC 핀 1/5/6/7을 GND로 묶지 않습니다. 전원을 분리한 DUT의 핀맵·각 선 저항도 확인합니다. 발룬 권선의 DC 경로와 실제 오접속을 회로 기준으로 구별합니다.

  6. 배치 고정 후 낮은 레벨부터 확인

    VNA 케이블 2개, 공통 보드 2장, 패치/어댑터와 미사용 SMA 로드 6개를 고정합니다. 사진과 개체 ID를 남긴 뒤 아래 측정 절차를 진행합니다. CT·shield·페어·배치를 바꾸면 해당 보정의 재사용 조건을 다시 확인합니다.

현행 문서의 조립 확인 순서를 정리한 것입니다. 실물 작업 성공·고정 기구 완성·제조 승인을 뜻하지 않습니다.

05 · 측정과 데이터

양쪽 O/S/L과 Thru를 측정합니다

자작 thru의 전체 S-parameter를 다른 지그로 미리 측정해 오라는 절차가 아닙니다. 7회는 Port 1의 O/S/L 3회 + Port 2의 O/S/L 3회 + Thru 1회를 뜻합니다. 표준 키트 7세트가 아닙니다. UnknownThru는 상호성, 충분한 전달, 실제 극성과 대략적인 편도 지연을 사용합니다. O/S/L의 모델과 재체결 변화는 독립 확인이 필요합니다.

Port 2 O/S/L은 S22입니다. 착오를 줄이려면 O/S/L도 .s2p로 저장하고 설정에서 해당 파일을 지정합니다. .s1p만으로 실제 취득 포트를 알아낼 수는 없습니다.

출력은 100 Ω 유효 차동 2포트 .s2p, IL/RL·위상·지연 CSV, 그래프 PNG와 출처 JSON입니다. 첫 SMA 보정은 계속 켜 둡니다. LibreVNA 화면에 두 번째 보정을 자동 업로드하는 기능은 아닙니다.
