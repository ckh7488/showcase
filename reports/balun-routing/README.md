# Balun · 차동 배선의 길이와 대칭

Molex 5핀 수동 측정 어댑터의 세 CAD를 같은 조건으로 비교한 인터랙티브 보고서입니다. 실제 배선의3D 보기와 각 CAD의 openEMS 계산값을 연결합니다.

## 자료와 계산 범위

- 원본: [ckh7488/balun_test](https://github.com/ckh7488/balun_test)
- 비교 버전: `8826733` → `acf8225` → `215cabd`. 전체 커밋과 형상 근거는 `data.json`, 계산 입력 해시는 `rf-data.json`과 증빙 ZIP에 있습니다.
- 주파수: **1–150 MHz, 1 MHz 간격**. A/B 두 페어의 Sdd11·Scd21·Sdd21을 계산했습니다.
- J1 RJ45의 PCB 단자부터 J2 Molex의 PCB 단자까지 모델링했습니다. 신호선·패드·저장된 기준면·신호 및 SHIELD 비아를 포함했고, 다른 단자도50 Ω으로 종단했습니다.
- 서로 다른 두 입력 상태의 입사파와 반사파를 이용해 순수 차동 입력에 대한 응답을 추출했습니다. 차동 기준은100 Ω, 공통 기준은25 Ω입니다. 개별 구동의 단순 출력/입력 비율을 Scd21로 쓰지 않습니다.
- nominal CAD 유전율과 PEC 도체 모델입니다. 유전체/도체 손실과 솔더마스크, 커넥터 몸체, 케이블, 제조 편차는 제외했습니다. 삽입손실은 이 모델에서의 전달 감소이며 실제 제품의 전체 감쇠가 아닙니다.
- 시간 기록의 끝부분, XY 격자 변경, 대표 페어의 경계 조건 변경을 비교했습니다. 관측된 차이는 본문과 `rf-data.json`에 있으며, 제조 오차나 통신 합격 기준으로 해석하지 않습니다.

## 데이터

- `data.json` / `data.js`: 세 CAD의 선로·길이·버전 근거
- `pcb-details.js`: 실제 패드·기준면·SHIELD 비아의3D 표시 자료
- `rf-data.json` / `rf-data.js`: 주파수별 수치·복소수 결과·계산 조건·검증 기록
- `rf-results.csv`: 세 안 × 두 페어 × 두 격자의 전 대역 비교
- `rf-evidence.zip`: 원시 포트 파형, 실제 CSXCAD 형상 XML, 구리 형상, 격자 및 재현 스크립트

`data.json`의 `historical_em`은 별도 RJ45–M12 모델의 이전 대화 기록입니다. 현재 RF 표와 곡선에는 해당 값을 사용하지 않습니다. 현재 보고서의 수치는 세 Molex CAD를 새로 계산한 `rf-data.json`에서 가져옵니다.

## 인터랙션과 유지보수

3D의 배선안 선택은 CAD/RF 표와 차트의 강조 상태에 연결됩니다. 기준면·실드 비아를 켜면 귀환 경로와 전체 패드를 함께 볼 수 있습니다. 보라색은 SHIELD, 회색은 미사용 패드이며 커넥터 몸체는 표시하지 않습니다. 선로는 실제 중심선과 폭을 따라 관 형태로 표시하며, 계산에는 별도의 동박층 구리 형상을 사용합니다. P/N의 mm 길이는 평면 선분 길이이며 시간 skew 실측값이 아닙니다.

RF 화면에서 A/B 페어, 지표,1–150 MHz 주파수를 선택합니다. 세 곡선은 항상 함께 비교하고, 점선으로 다른 격자의 결과를 겹쳐 볼 수 있습니다. 수치 변경 시 JSON/JS와 HTML의 기본100 MHz 표를 함께 갱신하고, CAD 커밋과 결과 입력의 대응을 확인합니다. 없는 주파수나 다른 CAD의 수치를 채우지 않습니다.

Sdd11·Scd21은 음수 dB가 더 낮을수록 해당 성분이 작습니다. 삽입손실은 0 dB에 가까울수록 좋습니다. 청록색은 두 격자에서 모두 유리하고 반복 계산 검토 목표를 만족한 값입니다. 검토 목표를 넘는 항목은 †로 표시하고 해당 주파수의 격자·기록 길이 차이를 제공합니다. 실제 추출값을 그대로 보존하며 † 항목의 절대값을 수렴한 확정값으로 취급하지 않습니다. 이 표시는 선택된 설계안이나 통신 합격을 뜻하지 않습니다.

접힌 반사·공통모드 설명의 파형은 정규화한 정현파 예시입니다. 실제 PCB 결과를 변경하는 기능이 아닙니다. 공통 테마와 파비콘만 `../../assets/`에서 불러오며, 나머지 런타임과 Three.js r128/MIT 라이선스는 이 폴더에 포함합니다.

변경 후 루트 정적 검사와 HTTP 환경에서 목록 → 보고서 → 복귀, 모든 주파수/페어/지표 전환, 실제 값의 바인딩,3D 조작, 격자 중첩, 내려받기와 모바일 화면을 확인합니다.
