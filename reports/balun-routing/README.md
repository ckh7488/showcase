# Balun · 차동 배선의 길이와 대칭

Molex 5핀 수동 측정 어댑터의 세 CAD 버전을 비교하는 인터랙티브 설계 검토본입니다. `index.html`에서 배선 버전·페어 선택, 3D 회전·확대, 세 안의 수치 비교와 접힌 신호 설명을 제공합니다.

## 자료와 범위

- 원본 저장소: [ckh7488/balun_test](https://github.com/ckh7488/balun_test)
- 비교 커밋: `8826733` → `acf8225` → `215cabd`. 전체 커밋 ID와 원본 `design.json`의 SHA-256은 `data.json`에 있습니다.
- 각 커밋의 KiCad 신호 선분·선폭·층·비아를 추출했습니다. 페어별 평면 선분 길이 합은 원본 `design.json`과 0.00001 mm 이내로 대조했으며, 02·03안은 저장소의 `docs/molex-routing/comparison.json`과도 대조했습니다.
- 보드 외형은 위치 안내용입니다. 패드·커넥터 몸체·실드면을 포함한 전체 전자기 모델이 아닙니다. mm 단위 길이 차이는 커넥터 내부 지연을 포함한 시간 skew 실측값이 아닙니다.
- 세 CAD에 대응하는 openEMS 원본 결과는 미확보이며, 세 안의 RF 비교는 미완료로 표시합니다. 계산값이 없는 표를 완성된 비교처럼 내세우지 않습니다.
- 03절 RF 표는 이전 대화 「차동신호 배선 비교」의 RJ45–M12 두 안 요약값 네 개를 항상 보여줍니다. 원본 solver 결과를 독립 검증한 값이 아니며, 위 세 Molex CAD에 대응시키지 않았습니다. 이 보고서 게시 과정에서 시뮬레이션을 새로 실행하지 않았습니다.

## 인터랙션과 유지보수

`data.json`과 `data.js`는 같은 데이터입니다. 값을 갱신하면 두 파일 및 HTML 비교표를 함께 갱신하고, CAD 버전과 수치의 대응을 확인합니다. CAD 표의 강조는 현재 3D 선택입니다. 별도 RF 표의 청록색 값은 같은 지표에서 성분이 더 작다는 뜻이며, 3D 선택과 연동하지 않습니다. RF 지표 버튼은 설명만 바꾸고 네 수치는 항상 표시합니다.

반사·공통모드 설명은 기본적으로 접혀 있습니다. 도착 시간 예시는 정규화한 정현파와 0 또는 0.15 주기의 지연으로 P/N 평균을 보여주며, 실제 PCB 해석값을 바꾸지 않습니다. 정의와 표기 출처는 본문에 연결되어 있습니다.

공통 테마와 파비콘만 `../../assets/`에서 불러옵니다. 나머지 런타임 파일과 Three.js r128 및 MIT 라이선스는 이 폴더에 포함됩니다. 루트 `reports.json`에서 카드 한 개로 등록하며, `../../`로 라이브러리에 돌아갑니다.

변경 후 루트의 정적 검사기를 실행하고, HTTP 환경에서 카드 → 보고서 → 목록 복귀, 세 안 선택과 표/3D 연동, 페어 강조, 3D 조작, 접힌 설명, 모바일 표 스크롤을 확인합니다.
