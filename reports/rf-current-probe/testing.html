RF 전류 프로브
점검·교정·측정 절차서

조립한 프로브와 지그를 무전원 점검한 뒤, VNA 연결을 네 단계로 바꿔 측정합니다. 상대 응답부터 확보하고, 조건을 입증한 범위만 전류로 환산합니다.

먼저 1–100 MHz에서 재현성을 확인합니다. 100 kHz–300 MHz는 전체 개발 목표, 500 MHz는 특성 확인·확장 목표입니다. 아직 측정 완료 사양이 아닙니다.

먼저 상대 응답을 확보합니다. 전류 모델과 기준면이 확인된 범위만 전류로 환산합니다.

  1. 조립 절차 A08의 무전원 점검 기록을 확인합니다. 실제 헤드·코어·턴 수·지그 리비전이 이 문서와 다르면 차이를 기록하고 해당 조립·시험 단계부터 재확인합니다.
  2. 측정 ID별 새 폴더를 만들고 헤드 ID, 지그 ID, 장비 HW/FW/GUI 버전, 케이블·어댑터·부하·교정키트 ID와 사진을 저장합니다. 이전 측정 파일은 덮어쓰지 않습니다.
  3. LibreVNA와 테스트 케이블 2개, 맞는 성별의 SOLT 표준, 대역·전력 정격이 확인된 외장 50 Ω 부하 1개를 준비합니다. 커넥터 모델·외형·어댑터를 확인하고 케이블을 별도로 지지합니다.
  4. RF OFF 상태에서 시작합니다. 아래 순서에 따라 케이블을 연결하고 수신기/부하가 올바른지 확인한 뒤 RF를 켭니다.

캘리브레이션: 연결을 네 번 나눕니다

P1은 신호를 보내고, P2는 받습니다. 단계를 누르면 케이블과 50 Ω 부하의 위치가 바뀝니다.

연결을 바꿀 때는 RF OFF. 재배선 후 일차 경로와 프로브 출력의 종단을 확인하고 RF를 켭니다. 아래는 제한된 저에너지 실험실 시험 절차입니다.

0 / VNA 오차부터 정리

케이블 끝에서 O/S/L/T 교정

VNA와 두 테스트 케이블의 영향을 교정합니다. 이 단계만으로 프로브의 감도가 정해지는 것은 아닙니다.

  1. 실제 장비 HW/FW/GUI, 케이블·표준의 모델과 성별을 확인합니다.
  2. 각 케이블 끝에 Open / Short / Load를 순서대로 연결하고 두 끝 사이의 Thru를 측정합니다.
  3. 지원되는 전체 2포트 교정을 적용하고 검증용 부하·Thru를 다시 연결해 확인합니다.

1차 경로와 프로브 출력에 각각 종단이 필요한 이유

지그의 중심 도체와 귀환은 일차 회로이고, 권선·프로브 출력은 별도의 이차 회로입니다. 2단계에서는 P2가 일차를 종단하고 외장 부하가 프로브를 종단합니다. 3단계에서는 외장 부하가 일차를 종단하고 P2가 프로브를 종단합니다. 하나의 출력에 50 Ω 두 개를 병렬로 붙이는 이중 종단과는 다릅니다.

RF 케이블·부하를 분리한 상태에서 지그 IN–OUT 중심끼리, 외피끼리 연속성을 확인하고 중심–외피 분리를 확인합니다. 프로브 SMA 중심–외피에는 권선의 낮은 DC 저항이 보일 수 있으며 정상입니다. 일차 도체와 권선의 의도치 않은 도통을 따로 검사합니다. DMM 검사는 내전압 시험이 아닙니다.

교정키트의 성별·모델·Thru 지연을 실제 구성에 맞춥니다. 알 수 없는 어댑터를 길이 0의 이상적인 Thru로 입력하지 않습니다. 단순 Thru 정규화만 했다면 전체 2포트 교정으로 기록하지 않습니다.

측정 파일을 비교하는 순서

  1. 지그와 삽입 영향: 1단계의 fixture_A02_empty.s2p에서 S11·S21·위상을 먼저 봅니다. 1–100 MHz S11 ≤ −20 dB를 초기 목표로 삼되, 공진·손실·기준면을 함께 검토합니다. 2단계 파일과 같은 주파수 축에서 비교해 헤드를 붙였을 때 달라진 구간을 표시합니다. 2단계의 S21을 프로브 감도로 사용하지 않습니다.
  2. 레벨과 반복성: 3단계 연결을 유지하고 정격 내에서 −30 / −20 / −10 dBm 시작안을 비교합니다. 각 레벨에서 평균이 갱신된 완전한 스윕을 저장합니다. 이어 RF OFF에서 집게를 완전히 열고 같은 위치에 다시 닫는 작업을 최소 5회 수행하며 각 회의 파일·사진을 남깁니다. 케이블은 가능한 한 같은 위치로 유지합니다.
  3. 위치 민감도: RF OFF에서 중앙 SIG에 대한 헤드 위치를 바꾸고, 다시 원래 위치로 복귀해 비교합니다. 고정 브래킷에서 가능한 이동만 사용합니다. PCB를 휘거나 고정 구멍을 억지로 늘리지 않습니다. 이동이 제한되면 그 범위를 기록하고 별도 위치 비교용 지지 설계로 이어갑니다.
  4. 직접 픽업·잡음: P1→지그 IN, 지그 OUT→외장 부하, 헤드 출력→P2를 유지합니다. RF OFF에서 헤드를 중앙 다리에서 분리한 뒤 코어를 닫아, SIG를 감싸지 않는 인접 위치에 지지합니다. 케이블 배치를 기록하고 fixture_A02_direct_pickup.s2p로 저장합니다. 별도로 소스 RF OFF의 수신기 잡음을 기록합니다. 헤드 이동 자체가 결합을 바꾸므로 이 대조는 누설의 지표이며 완벽한 제거값이 아닙니다.
  5. 상쇄 대조: 왕복 도체를 함께 감싸는 시험은 별도의 절연된 저에너지 왕복 루프에서 수행합니다. 한 도체만 감싼 경우와 두 도체를 함께 감싼 경우를 비교하고 각 구성의 일차 전류를 검증합니다. 현재 평판 보드의 GND 레일을 잘라 옮기지 않습니다. 적합한 대조 루프·전류 검증이 없으면 이 시험은 미실행으로 기록합니다.

귀환선을 옮기면 일차 전류도 바뀔 수 있으므로 같은 소스 레벨만으로 동일 전류를 가정하지 않습니다. 목표 미달 구간과 원시 데이터를 보존하고 원인을 기록합니다. 잡음·깊은 null·클리핑·미평가 구간은 마스킹하고 대역 밖으로 외삽하지 않습니다. 목표 충족만으로 전체 측정 정확도가 보장되지는 않습니다.

04

그래프를 얻은 다음, 언제 A로 바꾸나요?

S21은 입력 대비 출력의 비율입니다. 지그 전류가 검증되어야 감도 ZT를 구할 수 있습니다.

먼저 상대 응답, 그다음 전류

상대 단계: 같은 지그·배치·체인에서 5턴의 응답과 재장착 변화를 비교합니다. 전류 모델이 없으면 ZT와 A 값을 비워 둡니다.

정량 단계: 코어 위치의 전류, 기준면, 누설·잡음·선형성·반복성을 확인한 구간에서만 ZT를 계산합니다. 좋은 S11 하나만으로 이 조건들이 모두 증명되지는 않습니다.

ZT(f) = Vout(f) / IΣ(f)

Vout은 정의된 50 Ω 부하에 걸리는 전압입니다. 이후 같은 체인의 유효한 주파수에서 IΣ = Vout / ZT로 환산합니다.

S21 × 50 식과 1−S11 보정의 조건

동일한 실수 50 Ω 기준 임피던스, 충분한 정합, 코어 전류를 입력 진행파로 근사할 수 있는 지그, 정리된 케이블·기준면과 50 Ω 출력 부하에서만 |ZT| ≈ 50|S21|을 적용합니다. 위상은 코어 위치까지의 지연을 따로 확인해야 합니다.

ZT = 50 S21 / (1−S11)은 입력 기준면의 전류와 코어 위치의 전류가 같고 분기 전류·지연의 영향이 정리된 모델에서만 유효합니다. 조건이 안 맞으면 코어 전류 모델 HI가 필요하며, 확보 전에는 상대 측정을 유지합니다.

Tekbox 매뉴얼의 S21+34 관계를 참고하되 같은 페이지의 전력 차 식은 부호가 불일치합니다. 정의상 S21[dB] = Pout−Pin이므로 계산에는 Pout−Pin+33.9794를 적용합니다.

CALCULATED · 설명용 예제

이상적인 정합 50 Ω 조건이라면

실제 PCB 지그의 측정값을 넣는 도구가 아닙니다. 환산식의 의미를 보여주는 계산입니다.

선형 진폭비0.1000
|ZT| = 50 × 진폭비5.000 Ω
전류 = 전압 ÷ |ZT|1.000 mA RMS

같은 주파수·교정 체인에서 단일 정현파의 RMS 값끼리 계산합니다. 이 예제는 센서 감도·최소 검출 전류를 보장하지 않습니다.

50 Ω 교정지그의 전달 임피던스 관계는 Tekbox TBCPx 교정지그 매뉴얼을 참고했습니다. 현재 PCB 지그의 정합과 전류 모델은 실측 전입니다.

06

스코프로 옮기면 전압부터 저장합니다

VNA의 교정 결과가 스코프 내부 응답까지 보정해 주지는 않습니다.

프로브 SMA→검증된 감쇠·보호→SMA–BNC 케이블→스코프 내부 50 Ω

단일 주파수 비교

VNA 측정을 저장하고 RF OFF에서 재배선합니다. 벤치 소스는 sweep에서 CW, P1만 활성화로 바꿉니다. 파형에 고조파가 있을 수 있으므로 기본파 RMS를 따로 분석합니다.

잠정 장비는 Tektronix MSO4054입니다. 실물 모델·입력 상태 확인 후 DC coupling / 50 Ω / Voltage 1× / FULL / Sample 설정안을 적용합니다. 내부 50 Ω를 사용하면 외장 feed-through 50 Ω를 병렬로 더하지 않습니다.

전류 환산을 허용하는 조건

같은 헤드·권선·케이블·감쇠기, 같은 출력 기준면, 유효 ZT와 스코프 응답·부하가 확인되어야 합니다. VNA 연결에 사용한 BNC–SMA 어댑터를 제거했다면 그 영향도 정리해야 합니다.

확인 전 결과는 V 단위입니다. 펄스의 최대 전압을 한 주파수의 ZT로 나누지 않습니다. 감쇠기를 서지 보호기로 간주하지 않고, 현장 적용 전 보호·삽입 영향·순 DC 영향을 확인합니다.

50 Ω 수신기와 전류 환산의 기본 관계: Tekbox RF 전류 프로브 FAQ. 실제 장비 설정·안전 조건은 해당 모델과 사용 체인에서 별도로 검증합니다.

헤드 ID·리비전, 코어, 턴 수·극성, 차폐, 지그 ID, 케이블·부하·감쇠기 ID, 교정 ID·기준면, 출력 레벨, 주파수·IF BW·평균, 도체 위치, 온도와 시각을 기록합니다.

코어·권선·차폐·측정 체인이 바뀌면 교정의 재사용 가능성을 검토합니다. 원시 파일을 덮어쓰지 않고 새 기록으로 남깁니다.

현재 확보한 증거와 아직 없는 것
  • 헤드 PCB A0.2: 저장된 설정 기준 ERC/DRC 위반 0건. 이는 RF 성능 검증이 아닙니다.
  • 집게 A0.3: 국소 보강 및 공칭 CAD 검사 기록. 출력 공차·강도·실물 맞춤은 미검증입니다.
  • 분석 코드: 2026-09-16 저장 로그의 110개 자동시험 통과와 합성 리허설. 실측 데이터를 대신하지 않습니다.
  • 평판 PCB 교정지그 A0.2: 새 저장 파일의 ERC/DRC와 공칭 전류 경로·간격을 재검사했습니다. RF 성능은 미측정입니다.
  • 실제 ZT 교정표, 유효 대역, 최소 검출 전류, 허용 전류·내전압·현장 보호 정격은 아직 없습니다.

설계 근거와 상태 설명 · 이 문서의 원본 식별·해시

다음 실험은 조립·무전원 점검 → 지그 through → 5턴 상대 S21 → 반복성·누설 비교입니다. 그 결과로 유효 대역과 다음 설계 변경을 결정합니다.

변경

설계가 바뀌면, 바뀐 부분부터 다시 확인합니다

설명은 공정별로, 숫자·부품·포트 위치는 공통 설계 데이터로 관리합니다.

현재 기준은 지그 A0.2 · 헤드 A0.2 · 집게 A0.3 · 5턴입니다. 이 조합을 한 개의 설계 ID로 묶고 조립·시험 기록에도 같은 ID를 남깁니다. 새 형상으로 바꿀 때 이전 그림만 교체하거나 이전 교정표를 그대로 사용하지 않습니다.

바뀐 항목문서에서 고칠 곳다시 확인할 것
PCB 외곽·창·동박·SMA 위치공통 설계값, 실제 CAD/PCB 그림, 조립 A01·A06·A07, 포트 좌표ERC/DRC·구경 안 전류 경로·개폐 간섭 → 지그 단독/헤드 장착 through → 전달·누설·반복성
코어·턴 수·리드·차폐부품/권선 정보, 조립 A02–A05, 측정 메타데이터닫힘·출력 연결 → 전달 응답·선형성·위치 민감도·반복성·직접 픽업
기둥·나사·출력물·패드조립 A02·A05·A07, 실제 부품 기록맞춤·끝 닿음·케이블 하중·개폐·코어 틈 → 재장착 반복성, 전류 경로 영향 시 RF 비교
케이블·감쇠기·부하·장비 설정시험 설정, 체인 ID, 기준면·원시 데이터새 기준면으로 VNA 교정·검증, 수신기 종단, 교정표 재사용 여부
설명/오탈자만 수정해당 절차 문단·문서 리비전기술 의미·링크·표시 확인. 설계나 시험이 바뀐 것으로 기록하지 않음

변경 전 원본과 측정은 보존합니다. 새 리비전은 변경 이유, 영향을 받는 단계, 다시 실행한 검사와 아직 하지 않은 시험을 함께 남깁니다. 지금 기록된 CAD·DRC 결과는 검사 당시 원본 해시에만 해당합니다.
