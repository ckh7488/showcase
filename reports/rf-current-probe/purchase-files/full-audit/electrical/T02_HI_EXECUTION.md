# A02 고정 형상 평가 패키지 — 설계·벤치 실행안

2026-09-21 · **PLAN / 미실행. A02 발주 승인이나 신규 설계가 아니다.**

목적은 현재 A02 형상을 그대로 평가하여 **유지 가능 대역과 전류 환산 방법**을 결정하는 것이다. 약242 Ω 단면 결과만으로 기하 재설계를 먼저 결정하지 않는다. 전류가 알려지면 지그가 모든 곳에서 정확히50 Ω일 필요는 없다. 다만 단순 `50×S21` 적용 조건은 별도다.

- 외곽144×92.7 mm, 완성 두께1.6 mm, 양면SIG/GND, 실제 채워진 동박과45개 비아를 사용한다. 중심 다리8 mm/SIG6.8 mm, 창33.75 mm, 귀환 안쪽|x|51.3 mm. SMA 중심 간68.7 mm.
- PCB 좌표의 J1=(72,12), J2=(72,80.7) mm. 기구 좌표 x=PCB x−72, z=PCB y−40. 코어 중앙z=6.35 mm를 전류 관측 기준으로 명시한다.

## 2. 제작 전 모델 검토 — 형상을 바꾸지 않고 할 일

### 빈 지그부터

1. 두 SMA 실제 launch와 중심/귀환 동박, 기판 창, 비아를 포함한 전체 3D 도체를 가져온다. 현재2D 단면을68.7 mm 전체로 늘려 전체 지그 모델이라고 하지 않는다.
2. P1/P2를 두 SMA 접속면의 TEM 기준면에 두고 실수50 Ω로 정규화한다. 단순 핀 사이 lumped port를 쓰면 기준면 차이와 launch를 포함/제외한 범위를 명시한다.
3. 반대쪽은50 Ω로 종단하여 각 포트를 순차 여기한다. `S11/S21/S12/S22`, 입력전류, 출력전류와 **코어를 지나는 SIG의 복소 도전전류**를 따로 저장한다. 중앙 전류는 단면의 두 SIG면과 필요한 비아 전류를 모두 포함한다.
4. 코어 길이를 덮는 여러z 단면의 전류도 저장하여 ‘입력 전류=코어 전류’ 가정을 확인한다. 공간 전류·누설/변위전류·외부 귀환으로의 결합을 확인한다. 한 위치의 전류만으로 실제 분포 결합이 완전히 표현되는지 검토한다.
5. `HI(f)=Icore(f)/a1(f)`를 A/√W로 저장한다. 여기 a1은 해당 기준면의 진행파이며 GUI 표시 dBm을 무조건 대입하지 않는다.
6. 두 단계 이상 메시/영역 수렴, 전하/전력 보존, reciprocity/passivity(적용 가능한 수동 조건), 포트 방향 반전, SMA 단순화 민감도를 확인한다. 포트/구리/비아 단순화로 생긴 오차가 전체 ±3 dB 목표에 어떻게 들어가는지 적는다.

필수 출력: geometry/stack-up/재료 출처, solver버전·설정·메시·경계·포트/기준면, 원시 장/전류, complex S2P, `hi_empty.csv`, `hi_vs_z.csv`, 수렴·민감도 표, 원본/소스 해시. 계산을 실제 `measurements/raw`에 넣지 않는다.

### 헤드 장착 조건

빈 지그의HI를 그대로 최종 교정에 적용하지 않는다. 실제 교정에서는 프로브 출력이50 Ω로 종단되어 일차 경로에 부하를 준다. 전체 헤드 EM 모델 또는 검증된 삽입 모델이 필요하며, 복소 투자율·권선 기생 성분·간극을 모르면 그 한계를 남긴다. 완전한 코어 모델 확보를 모든 초기 작업의 선행조건으로 만들지는 않는다. 빈 지그 모델을 먼저 계산하고 실물 T02 loaded와 대조하여 다음 모델 수준을 결정한다.

**이번 감사에서 전체3D 해석은 실행하지 않았다.** 현 저장 근거는2D 단면뿐이다. 공개표에 없는 코어 고주파 물성을 만들어 넣어 이 단계를 닫지 않는다.

## 3. 저에너지 실물 T02 — 조건 충족·승인 후 실행

실제 조립품이 없는 동안 아래는 계획이다. 모델 계산만으로 ‘실측 통과’를 기록하지 않는다. 모든 재배선은 RF OFF, 외부 전원·현장 케이블 없는 수동 벤치에서 한다.

| 순서 | 연결 | 저장할 원본 |
|---|---|---|

| 1 | P1→J1, J2→P2; 프로브 없음 | `fixture_empty.s2p` — 네 복소S |
| 2 | 같은 연결+헤드 장착; 헤드SMA→외장50 Ω | `fixture_loaded.s2p` — 네 복소S |

## 4. 판정: 구조 변경은 결과 다음에

- 기존 T02 초기 목표는1–100 MHz S11≤−20 dB. S22·손실·위상·공진·부하변화도 함께 기록한다. **목표실패=곧바로PCB폐기**가 아니고, current model/오차예산 검토 대상으로 분리한다. 목표를 바꿀 경우 이유를 기록한다.
- S11만 낮다고HI가 확정되지 않는다. port2port 특성이 같아도 내부 전류가 다른 회로는 가능하다. 구조모델 없이 검은상자 S2P만으로 국소전류를 역산해 ‘완료’하지 않는다.
- GradeA 비교용: 같은지그/헤드/출력체인에서 상대응답만 보고한다. 이것도 선형성·잡음·픽업·반복성 평가가 선행된다.
- GradeB 전류추정: 적용할HI/기준면과 오차예산이 확보된 주파수만 `ZT=√50·S21/HI`로 계산한다. 입력전류와코어전류가 같다는 증거가 있을 때만 `50·S21/(1−S11)`를 쓴다.
- GradeC 정량용: 독립기준과 비교한 오차/재현성이 필요하다. 센서의ZT와 명목VNA dBm으로 서로를 검증하는 순환논리를 쓰지 않는다.
- 유효대역은 위조건+선형성10±1 dB/입력10 dB변화,5회재장착±1 dB(1–100 MHz초기목표),직접픽업과상쇄20 dB초기목표,위치민감도,잡음/무클리핑을 함께 판정한다. SNR10 dB는 검출 기준이지 정확도보증이 아니다.
- 실제배치에서HI가 불확실하거나 누설/공진이 허용오차를 넘는다는 근거가 나온 뒤에만 기하/종단/정합소자 대안을 비교한다. 현재5.3 pF는 미채택 계산예시다.

## 5. 스코프로 넘기는 별도 단계

SMA→BNC 어댑터를 교정 때 포함했다가 제거하면 같은전달함수가 아니다. 기존 `END_TO_END_REHEARSAL.md`의 BNC끝 교정 또는 검증된2포트 adapter de-embedding 중 가능한 경로를 정한다. 스코프 자체 주파수응답·50 Ω입력 반사/부하차이도 별도 평가한다. 한계가 있는 어댑터 손실 한숫자만으로 제거하지 않는다.

처음은 RF OFF 재배선 후 CW/P1만 출력, CH1 내부50 Ω/DC/FULL/1×/Sample로 전압과기본파를 기록한다. 실제장비설정과 정격이 우선이다. 조건이충족된단일주파수RMS만현재코드로A환산한다. 광대역FFT전류/펄스피크/시간역복원은 구현·검증되지 않았다. 현장과외부에너지 입력은 보호부정격·잔류전압·왜곡·복귀 검토 전 보류한다.
