## 결론

**현재는 설계 검토용 시제품 패키지이며, 업체 승인만 받으면 전체 세트를 바로 제작·정량 측정할 수 있는 상태가 아니다.** 이전의 제작 준비 완료 설명을 정정한다. E03의 보류는 새로 온 업체 거절이 아니라 9월 18일부터 남아 있던 교정지그 전류 모델 검증이다.

## 첫 시제품 이후에만 확인할 일

- 실제 출력 공차·휨, 코어 접촉, 노브 마찰·유격, 반복 개폐와 고정력.
- SOL/THRU의 실제 표준 모델, 케이블 기준면, 빈 지그/프로브 장착 상태의 전류와 응답.
- 오실로스코프 전류 환산을 위한 BNC 기준면 및 수신기 응답. 어댑터 제거 후 같은 교정이라고 간주하지 않는다.
- 감도·유효 대역·직접 픽업·삽입 영향. 100 kHz–300 MHz는 목표이며 실측 사양이 아니다.
- 광대역 잡음/펄스의 전류 파형 복원은 미구현이다. 현재 소프트웨어의 기본파 RMS 계산과 구분한다.
- 현장 보호는 미선정이다. 감쇠기만으로 보호가 완성되지 않으며 첫 단계는 외부 에너지원 없는 저레벨 벤치 특성화다.

## 이번에 바로잡은 문서

1. 표지·설명서·조립절차·BOM·사용법·구매서·PCB 검토에 같은 현재 상태표를 연결했다. ‘선정’ 옆에 실제 조달 상태를 표시했다.
2. C04의 오래된 ‘팔로워 구매품 미확정’을 실제 선정 NBK 어깨나사로 정정했다. H05/B05/B07은 수정된 조립 경로와 실물 확인을 구분했다.
3. F14 날개너트 치수는 제조사 도면으로 확인했다. 남은 소량 판매·배송 확인과 분리했다.
4. 약 242 Ω 결과를 전체 지그 불량 또는 무조건 재설계의 근거처럼 읽을 수 있는 문구를 고쳤다.
5. 동판·패드·옛 지주·구형 구매 이연 문구는 역사 기록으로 구분하고 현재 결정·조립 제약을 갱신했다.
6. 플럭스2·작업용 로드7·인두팁 각1을 유지했다. 기존 공유카트9종과 통합 입력11종을 구분했다. 두 경로를 중복 주문하지 않는다.

## 실제 실행한 검증과 한계

- 소프트웨어 **110개 테스트 통과**. [원 결과](unit_tests.xml)
- 합성 연결 리허설 **연결9 / 기본파4 / 잘못된 사용 거부10**. [원 결과](synthetic_rehearsal/report.json)
- 저장 전위 **169,455점**의 전하·에너지를 독립 재적분해 단면 계산을 재현했다. 전체 3D 전자기 해석이나 실측은 아니다.
- 현재 PCB 두 개를 읽어 실제 구리 채움·접속을 대조했다. ERC/DRC는 현재 원본과 해시가 일치하는 저장 결과를 검토했으며 이번에 새 실행했다고 보고하지 않는다.
- 정확 F02 최대 외형으로 뒤 삽입58자세, M2×12 후보 정적·앞 인출61자세의 국소 간섭을 검사했다. 실제 나사산·마찰·출력 공차 시험은 아니다.
- 기존 125객체 형상, BOM58행·조립45단계·STL15종/20개 및 이전 검증의 원본 일치를 확인했다. 문서 링크와 오프라인 묶음은 발행 단계에서 별도 검사한다.

**CAD·Gerber·STL 및 주문 내용은 이번 감사에서 바꾸지 않았다.** 수정한 것은 현재 상태와 절차·구매 문서다. 새 전체 EM, 실제 조립, 교정·RF 성능, 결제·현장 시험 결과는 없다.
