## 2. 측정 순서 — 연결 변경은 항상 RF OFF

시작 설정안: 1~100 MHz / 1601점 linear / -30 dBm / IF BW 1000 Hz / 평균 4회 시작안, 실제 값 기록. 실제 지원값·정격을 우선하고 설정을 저장.

1. 두 테스트 케이블 끝에서 실제 모델·성별이 맞는 O/S/L/T로 지원되는 2포트 교정. 교정 ID·기준면·재접속 확인을 저장.
2. 헤드 없이 P1 → 지그 J1 · IN, 지그 J2 · OUT → P2. 외장 부하 없음. fixture_A02_empty.s2p 저장.
3. RF OFF. 헤드 장착, 헤드 출력 → 외장 50 Ω. P2는 지그 J2 · OUT에 유지. fixture_A02_probe_loaded.s2p 저장.
4. RF OFF. P2 케이블은 지그 J2 · OUT → 헤드 출력으로 이동. 외장 50 Ω는 헤드 → 지그 J2 · OUT으로 이동. 두 종단 확인 후 RF ON.
5. fixture_A02_probe_transfer.s2p 및 같은 이름의 JSON에 설정·체인·위치·시간·교정 ID 저장. 모델 미검증이면 relative.
6. 소스 레벨·재장착 최소 5회·도체 위치·상쇄·직접 픽업·잡음을 비교하고 실패 구간도 보존.

## 4. 스코프

RF OFF 후 재배선. CW/P1만 출력. 실제 모델의 입력·정격·50 Ω 설정 확인. 원시 전압 파형을 먼저 저장. BNC 기준면, 체인, 수신기 응답·부하가 맞을 때만 단일 주파수 기본파 RMS를 환산. VNA용 어댑터 제거와 감쇠 중복 보정 주의. 광대역 펄스 피크를 단일 ZT로 나누지 않음.
