## 수정한 것

1. 뚜껑 중앙 M4×25 → M4×30: 너트 밖 나사끝 공칭 여유 0.2 → 5.2 mm.
2. 바닥 M4×16 → M4×20, 아래에서 삽입: 머리는 바닥 포켓 안, 너트는 위쪽. 책상 면과 머리 공칭 여유 2.1 mm.
3. PCB 홀더: 내창과 PCB·SMA·권선 위치는 유지하고 외벽 2.5 → 5.5 mm 및 하단 블록 보강. 추가 부품 없음. 자동 박벽 경고는 새 파일에도 남아 있어 제조사 판정을 기다린다.
4. C07: 기성 암나사 노브 + 완성 M6×120 전산봉 + 잼너트 + 평와셔. 압입·절단 없는 조합으로 형상 검증. 클램프 출력물은 그대로.
5. 기존 클램프 장착 손나사는 25 mm 들어올리고 바깥으로 빼도록 절차 수정. 곧장 40 mm 들어올리는 경로는 프레임에 닿는다.
