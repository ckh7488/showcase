# A14 문서 동기화 — 독립 조립 순서 감사

2026-09-21 · **CALCULATED / 명목 CAD와 문서 순서 검토**. 제품 CAD·Site·Atlas는 이 검토에서 수정하지 않았다. 이전 A14 검사 978자세를 다시 돌리지 않고, 이번 문서/기성품 변경에 필요한 구간을 추가로 확인했다.

## 발견과 처리

| 항목 | 확인된 문제 | 필요한 수정 / 검토 결과 |
|---|---|---|
| 분할 조립 누락 | 구 안내서는 A13의 LowerBody, UpperLid, CommonBase 한 조각씩을 가정 | 코어·PCB 전에 하부 3조각, 상부 코어 전에 뚜껑 2조각, 모듈 설치 전에 바닥 3조각을 각각 선조립. 새 PA66 나사 10개·너트10개·와셔20개를 단계와 BOM에 연결 |
| 새 부품 이동 방향 | 초기 wrapper가 기존 검사와 다른 X/대각 이동을 표시 | 하부 팔 −Z, 우측 뚜껑 −Z, 바닥 중앙 +Y의 기존 확인 경로로 정정. 분해 슬라이더의 역순이 조립 방향 |
| **H05 PCB 통과** | 기존 −30°/Y−1.6 mm 경로는 A14 추가 roof와 실제 겹침 | **−45°/Y−4 mm**로 변경. 동일한 단일 회전축과 두 직선 이동이며 제품 변경 없음. 최신 `c718d11f…`에서 PCB/SMA 362자세 모두 간섭 없음 |
| PCB 원인 확인 | 외곽 보강만 보고 내부 경로도 같다고 판단할 수 없음 | 예전 자세(−30°, Y−1.6, Z+8)의 전체 LowerCenter 겹침 **21.2483 mm³**가 추가 roof 두 블록과의 겹침과 일치. 바닥/옆 외곽 보강이 아닌 roof 추가의 영향 |
| C07 기성품 선조립 | 일체형 노브축을 가정한 순서 | 스터드 끝10 mm 표시 → 상부 잼너트 → 노브 → 프레임 밖 맞조임 → 상부 와셔. 아래 구동너트·와셔·nyloc를 놓은 다음 위에서 축을 돌려 넣음 |
| 새 노브축 삽입 | 기성 조합의 회전/정적 외형만으로 삽입이 자동 증명되지 않음 | 최초 `8e547665…` 기준 선조립체 284자세 및 아래 하드웨어 앞쪽 선삽입78자세 통과. 나사산 없는 보어를 통한 **외형 검사**이며 나사를 밀어 끼우라는 뜻이 아님 |
| C04A 분해 끝자세 | 노브 +45Y와 잼너트 +65Y의 주차 위치가 중첩 | 노브를 +110Y로 더 멀리 두도록 root에 전달하여 반영. 실제 제품 결함이 아닌 표시 순서 문제 |
| 두 종류의 M6 너트 | 잼너트와 축 여유 조절용 nyloc의 역할/공구 접근 혼동 가능 | 위 잼너트는 노브/축 결합, 아래 nyloc는 축 여유. 위쪽 검토 접근은 +Z, 아래쪽은 **+X에서 공구를 고정하고 노브 회전** |
| B05/B07 | 좌측 고정 나사를 40 mm 곧게 들면 프레임에 접촉 | 25 mm 상승 → 바깥 X 방향. 기존 검증 결과를 재사용하여 표시 수정 |
| 느슨한 바닥 뒤집기 | 체결 전 세 조각을 통째로 뒤집으면 겹침이 분리될 수 있음 | 두 조각을 함께 지지해 한 체결점부터 걸고 나머지 체결. 손/작업대 지지는 강체 CAD에 포함되지 않음 |
| 자유 뚜껑 표시 | UpperLid 단일 이름만 탄성복귀 처리 | UpperLeft/Right는 각각 자유 형상으로 복귀; 중앙 연결 체결품·코어·고정바는 중앙 받침과 함께 이동. 평상시 중앙 연결 나사는 풀지 않음 |

## H05의 실제 설명과 키

아래 본체 선조립, SMA 납땜, 코어 권선은 먼저 한다. PCB 설치 중에는 아래 고정바와 M2 나사를 빼 두고, 권선 끝선은 경로 밖으로 앞으로 빼 둔다. PCB에 권선 끝을 미리 납땜하지 않는다.

삽입은 아래 분해 키의 역순이다. **아랫변이 앞으로 나오게 약45° 기울여 가져오기 → 장착 높이보다 약4 mm 아래에서 창 안으로 넣기 → 기울인 채 올리기 → 세워서 나사 체결**이다. 코어와 뒤 M2 너트를 남긴 CAD에서도 확인했다. 뒤 작은 너트를 손으로 잡는 편의성과 실제 끝선은 따로 확인해야 한다.

회전축 `[0, -36, 5.55]`, X축 회전. 표시 키:

```json
[[0,[0,0,0],0],[0.25,[0,0,0],0],[0.5,[0,0,0],-45],[0.65,[0,-4,0],-45],[1,[0,-4,40],-45]]
```

이는 실물에서 각도를 정밀 측정하라는 지시가 아니라, 통과 가능한 단순 경로를 보여주는 수치다. 출력 휨·공차·손 사용성은 실물 확인 항목이다.

## F09 / F11 / F12의 실제 조립 조건

### F09 — M6 사각 구동너트

- 필요한 모델 조건은 **M6×1, 정사각10×10 mm, 높이5 mm**다. 슬롯은 폭11.6/높이6 mm이며 공칭 축방향 여유1 mm가 있다.
- 앞쪽에서 넣고 축을 나중에 끼운다. 축이 이미 관통한 상태에서 옆으로 뺄 수 없다.
- 정확한 구매품의 최대폭/높이, 모서리·모따기, 실제 회전방지 접촉면, M6 피치, 버를 대조해야 한다. 외접 박스가 맞는 것만으로 회전방지를 증명하지 않는다.
- 이 여유는 방향전환 시 이동 지연이 생기는 조건이다. 상부 잼너트나 하부 nyloc를 더 조여 없앨 수 없다. 케이블을 조이는 방향으로 마지막 위치를 잡고 실제 중심 재현성을 확인한다.

### F11 — 하부 와셔

- 원래 t0.8 모델의 품번이 비어 있었다. 실제 후보 A(OD12.5/t0.8)와 B(기성 Fabory OD12/t1.6)를 각각197자세로 비교했고 둘 다 명목 간섭이 없다.
- root 채택 B안은 **Fabory 50060.060.001, ID6.4/OD12/t1.6**을 상하 공용으로 쓴다. 하부 와셔 Y40.2..41.8, 하부 nyloc Y34.2..40.2다. 와셔 윗면41.8과 프레임42 사이0.2 mm 목표는 유지한다.
- 단순히 두꺼운 와셔만 끼우는 것이 아니다. 아래 너트 위치도0.8 mm 내려 조절한다. 실제 부품 두께/평탄도/마찰과 반복 회전 후 유격은 미측정이다.
- 공구 그림도 기존 Y36..40에서 **Y35.2..39.2**로 내려야 검사한 위치와 일치한다. ‘아래 얇은 와셔와 혼동 금지’ 문구는 현재 상하 공용품과 맞지 않는다.

### F12 — 팔로워 어깨나사

- 기존 미선정 모델은 M4 나사8 mm + Ø5 어깨20 mm + Ø9×4 머리였다. 제조사 확인 후보는 **NBK SBSMS-M4-5-20**, 어깨 길이 최대20.25 mm, Ø5 f9, 육각홈2.5 mm다.
- 최대20.25 mm 외형으로 구동42/앞 삽입62/직선 드라이버 게이지42, **146자세**에서 간섭이 없다. 어깨 밑면 Z10은 유지되고 머리 밑면 Z30.25와 yoke 앞면 Z28 사이2.25 mm다.
- M4 나사범위 Z2..10, 너트 Z3.5..6.7이어서 공칭 너트 전체 물림3.2 mm와 끝돌출1.5 mm가 유지된다. 실제 완전 나사산·모따기·어깨 전이부·출력 공차는 별도 확인한다.
- 일반 M4 나사로 대체하지 않는다. 어깨가 턱에 앉아야 하며 조일 때 움직이는 yoke를 누르면 안 된다. 실제 부품으로 조인 후 전 구경에서 미끄러지는지 확인해야 한다.

## F05 손나사의 추가 확인과 채택 조합

Verpas 후보의 Ø7×4 허브 + Ø14×5 손잡이는 명목 Ø5.2 상부 홀보다 커서 받침면에 걸린다. 중심이 맞을 때 환상 받침면적17.2478 mm², 반경 폭0.9 mm다. 구멍5.5 mm와 최대 축편심을 가정하면 한쪽 최소폭은0이므로 이를 강도·공차 합격으로 표현하지 않는다.

M4×50은 현재 좌표에서 너트 끝돌출이 **0.4 mm**뿐이었다. ×55/×60 대안은 각각5.4/10.4 mm이며 세 길이 모두 각82 인출 자세에서 명목 간섭이 없었으나, 이는 해당 길이 실물 품번을 확보했다는 뜻이 아니다. 이 후보를 최종 구매품으로 혼동하지 않는다.

root 채택 대안은 **NBK KNFS-16-M4 관통 노브 + Fabory 20106.040.070 M4×70 전산봉 + 51080.040.001 M4 잼너트 + Essentra 17M04DIN34815 와셔**다. 두 개를 동일하게 선조립한다. 축 절단·압입을 요구하지 않는다.

- 좌표: 받침 와셔 Y40..40.8, AF7/H3.2 잼너트40.8..44, 노브 허브Ø8×6 Y44..50 + 손잡이Ø16×3.5 Y50..53.5. 전산봉−16.5..53.5이며 상면을 노브 상면과 맞춘다.
- 너트 끝돌출6.9 mm, 노브 관통 높이9.5 mm가 명목 나사 물림이다. 실제 완전 나사산·체결 토크·반복 풀림은 별도 확인한다.
- 두 묶음의8부품을80 mm까지 인출하는 **328자세**, 밖에서 잼너트를 맞조이는7 mm 스패너 외형 **26자세**를 확인하여 간섭이 없었다. 스패너는 입7.2/머리Ø12/두께3 mm의 명시적 게이지다.
- 잼너트를 전산봉에 먼저 넣고 관통노브 상면과 봉 끝을 맞춰 체결한 뒤, 잼너트를 노브 허브에 맞조인다. 와셔는 아래 봉 끝에서 넣는다. 평상시에는 이 잼너트를 풀지 않고 노브·봉·너트를 함께 돌린다.
- 개폐 화면은 `HeadHandScrews`뿐 아니라 새 `HeadClosureKnobs/JamNuts/Washers`도 함께65~70 mm 인출해야 한다. 65 mm 인출이면 봉 끝이 윗면보다8.5 mm 올라온다.

## 근거 파일과 한계

- `selected_pcb_path.json`: 최종45°/4 mm 경로와 roof 원인 확인. 검사 원본 `c718d11f…`.
- `sequence_checks.json`: 최초8e547665 원본의 추가 삽입 검사. **전체 pass=false는 옛 PCB 경로 실패를 보존한 것**이다. 노브축/선삽입 행은 통과했고 PCB는 위 최종 경로로 해결했다.
- `pcb_adjusted_path.json`, `pcb_motion_search.json`: 실패한 수직 이동 후보와 각도 탐색의 진단 기록. 제작 합격 근거가 아니다.
- `lower_washer_candidates.json`: 두 F11 후보의 국소 비교. A안은0.8 mm 명목이며 나중에 확인한 Accu0.7~0.9 mm 공차 전범위 검사로 읽지 않는다.
- `follower_max.json`: NBK 어깨 최대 길이의 후보 검사. 검사 원본 `c718d11f…`.
- `head_handknob_candidates.json`: Verpas 머리 포락 및 50/55/60 mm의 명목 대안 검사. 실제 SKU 확정과 별개다.
- `f05_stud_knob.json`: 채택된 관통노브/70 mm 봉 조합의 독립 외형·인출·외부 공구 검사. 최종 제품 CAD 반영·바뀌지 않은 부품의 동일성은 기구 담당 보고서를 함께 따른다.

모든 경로는 유한 개 강체 위치, 나사산 대신 여유 보어를 사용한다. 손·나사산 조임·마찰·탄성·출력 휨·크리프·내구성과 RF 성능을 측정하지 않았다. 수정되지 않은 기존 부품의 검사 재사용은 각 보고서 원본 해시와 제품 변경 동등성 보고서를 함께 봐야 한다.
