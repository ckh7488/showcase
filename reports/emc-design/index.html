큰 EMC 위험을 가려내는 설계 판단법

발생원 → 결합 경로 → 피해 회로. 이 세 가지를 연결하고, 작은 모델로 먼저 바꿀 구조를 고른다.

20 m 케이블·금속 함체·내부 모터가 있는 PALA720을 예로 든다. 아래에서 경로를 고른 뒤, 제품 조건과 계산 실험으로 판단을 확인한다.

교육용 계산과 제품에 대한 적용 판단이다. 신규 openEMS 결과나 EMC 합격 판정은 포함하지 않는다. 수식·시험 조건·출처는 상세 설명에서 확인할 수 있다.

이렇게 나누는 근거와 세 모델 비교

큰 취약점을 찾기 위해 처음부터 완제품의 모든 형상을 풀 필요는 없다. LearnEMC의 자기장 결합 예제는 자속의 결합 비율을 어림잡은 계산과 더 정확한 계산의 차이가 2dB 미만인 사례를 보여준다. 몇 dB 수준의 추정으로도 잠재적인 누화 문제를 가려낼 수 있다는 설명이 따른다. 이는 해당 결합 문제의 예이며 모든 EMC 해석의 허용 오차를 정한 규칙은 아니다.[4]

더 직접적인 자료는 Imbalance Difference Modeling이다. LearnEMC는 케이블 내부의 복잡한 구조를 전송선·정전계 모델로 다루고, 외부 공통모드 거동은 단순화한 도체 모델로 연결하는 방법을 설명한다. 설계 검토에서는 특정 시험 배치 하나를 정밀하게 재현하기보다, 불균형 변화와 최악 조건의 여기 크기를 평가하는 접근을 제시한다.[6]

적용 판단: PALA720은 openEMS를 유지하되, 세 종류의 전달 경로를 분리해서 계산한다. ① 케이블 접속부에서 회로로 넘어오는 외란, ② 내부 구동부에서 민감 회로로 넘어오는 외란, ③ 외부 RF가 함체를 포함한 구조에 결합하는 경로다. ESD·EFT·서지의 보호소자 동작은 별도 회로 해석으로 연결한다.

첫 분석 대상우선하는 근거지금 생략할 세부
20m 케이블의 접속·실드·0V·차동쌍 경계제품 바깥과 회로가 직접 연결되는 큰 구조이며, 공통모드 전류와 모드 변환이 함께 존재할 수 있음외부 케이블 전체의 미세 3D 형상. 먼저 단자 외란과 종단 임피던스로 대체
벅·모터 구동부와 PHY 전원·기준전위확실히 존재하는 내부 전압·전류 변화원이며 외함의 외부 차폐 효과를 받지 않음회전자·기어·구동 제어 전체. 먼저 스위칭 노드와 전류 루프로 대체
외부 RF와 함체의 접합부·관통부실제 구조에 길게 이어지는 접합부가 있고 RF 접촉 상태가 확정되지 않음두꺼운 금속 벽의 미세 조직·도장 질감·작은 장식 형상

이 순서는 사전 설계 검토의 우선순위다. 아직 측정하지 않은 현장 외란의 세기 순위나 현장 고장 원인의 확정 순위는 아니다. 케이블과 함체가 효율적인 안테나 구조를 만들 수 있다는 근거, 내부 스위칭원이 실제 존재한다는 사실, 민감한 Ethernet 경계가 있다는 사실을 함께 사용한 판단이다.[5][11]

2. 노이즈는 네 개의 서로 다른 질문으로 분류한다

LearnEMC의 기본 틀은 발생원–결합 경로–피해 회로다. 세 요소가 연결되어야 간섭이 발생한다. 경로는 전도, 전기장, 자기장, 방사 결합으로 나누며, 하나의 사건에 여러 방식이 이어질 수 있다.[1]

분류할 질문예설계에 쓰는 이유
무엇이 발생시키나?무전기, 접촉기, 벅 스위칭 노드, 모터 구동 전류, 정전기를 띤 사람크기·주파수·상승시간·반복 조건을 정함
어떤 파형인가?연속 RF, 빠른 반복 펄스인 EFT, ESD, 비교적 에너지가 큰 서지, 전원 저하동작 방해와 에너지·과전압 문제를 구분함
어떻게 결합하나?공유 임피던스, 기생 C, 상호 L, 전자기파 수신최소 등가회로와 수정할 구조를 정함
어디에서 문제가 되나?RX 차동 입력, PHY 공통모드 범위, 전원, RESET, RBIAS, 절연 경계어느 전압·전류를 관측하고 무엇과 비교할지 정함

RF·ESD·EFT·서지는 외부 노이즈의 완전한 네 분류가 아니다. RF가 케이블에 결합하면 장으로 들어와 전도 전류가 되고, 접속부의 불균형에서 차동 잡음으로 바뀔 수 있다. ESD도 함체 표면 전류, 내부 장, 배선 전류를 동시에 만들 수 있다. 따라서 시험 이름만으로 PCB 안의 경로를 결정하지 않는다.

외부 RF → 케이블·함체에 공통모드 전류 → 접속부의 불균형·공유 경로 → RX 차동 잡음 또는 PHY 전원 변동

“칩을 직접 지나가는 전선이 없다”는 것으로 경로를 배제할 수 없다. 입력 전압은 두 지점 사이의 값이다. 수신기 기준전위가 변하거나 두 입력으로의 결합량이 다르면, 칩과 멀리 떨어진 연결부도 입력에 영향을 준다. 공통임피던스 결합은 바로 이 문제를 간단한 회로로 설명한다.[2]

3. 무엇을 포함하고 무엇을 생략하는가

첫 기준은 사용 환경과 제품의 실제 연결부다. IEC 61000-6-2:2016은 산업용 일반 내성 규격이며, 관련 제품·제품군 규격이 없을 때 적용한다. 그 범위는 관련성이 있는 외란을 포트별로 선택하며, 모든 극단적인 사건을 포괄하지 않는다. 따라서 “공사현장 전체를 모델링해야 한다”는 결론은 나오지 않는다.[8]

가장 명료한 생략 사례는 외부 도선이 전혀 없는 건전지 센서다. IEC 61000-4-6은 RF와 결합할 외부 도선·케이블이 없는 장비를 해당 전도 RF 시험의 범위에서 제외한다. 반면 금속 함체가 있다는 사실만으로 외부 RF나 ESD가 제외되지는 않는다.[9]

조건을 바꾸며 보는 분석 범위

아래는 원리에 따른 설계 선별표다. 인증용 시험 적용 판정을 자동화한 표가 아니다. ‘케이블 없음’은 충전·디버그·접지선을 포함해 사용 상태에서 외부 도선이 전혀 없다는 뜻이다.

항목선별 결과왜 그렇게 보는가
생략 근거·시험 입력·규격 판본 확인

생략에는 서로 다른 세 가지 근거가 있다

  1. 경로 자체가 없음: 외부 DC 전원이 없는 장치의 DC 입력 외란. 해당 포트 분석을 뺀다.
  2. 설계 범위 밖의 사건: 직접 낙뢰 전류를 받아내는 구조 설계는 일반 RF·EFT·서지 분석과 별도다. 크레인 설치에서는 시설 측 낙뢰 보호·배선 조건을 설계 전제로 기록하고, 유도 서지는 남긴다.
  3. 정량적으로 작음: 특정 경로의 최대 예상 입력과 전달량을 곱해도 정해진 허용 여유보다 충분히 작으면 후순위로 둔다. 조건이 바뀌면 다시 검토한다.

‘현재 모델에서 생략’과 ‘제품 설계에서 무시’도 구분한다. 외부 케이블을 단자 전압으로 바꾸는 것은 케이블로 인한 외란을 유지하면서 외부 수신 과정을 모델 밖으로 옮기는 일이다. 외부 전압 자체를 0으로 두고 통과했다고 하는 것과 다르다.

입력 세기를 모를 때의 출발점

사용 환경에 맞는 제품 규격을 먼저 확인하고, 없으면 산업용 일반 규격을 설계 출발점으로 삼는다. 전도 RF는 150kHz–80MHz, 방사 RF는 해당 요구 대역의 장 세기를 입력 조건으로 정한다. 예를 들어 산업용 Ethernet 실측 자료는 80MHz–1GHz의 10V/m 요구를 다룬다. 전체 80MHz–6GHz를 10V/m로 검토한다면 그것은 별도의 설계 여유를 둔 자체 조건이며, IEC의 모든 구간이 동일하게 10V/m라는 뜻은 아니다.[9][10][12]

초기 모델은 1V/m 또는 단자에서 실제로 측정된 1V 공통모드 전압으로 정규화하면 된다. 이후 요구 입력을 곱한다. 다만 전도 RF 시험기의 ‘10V’와 PCB 단자에서의 실제 전압은 소스·결합기·부하 임피던스 때문에 같지 않을 수 있다. 시험기 레벨을 칩 핀에 직접 인가하는 식으로 옮기지 않는다.

판본 구분: IEC 61000-6-2:2016의 기본 시험 규격 인용에는 날짜가 붙어 있다. 현재 IEC 카탈로그의 61000-4-3:2020, 61000-4-6:2023, 61000-4-2:2025를 그 인용 판본과 임의로 섞지 않는다. 여기서는 물리와 범위 선정 원칙을 학습하며, 최종 시험 계획에서는 실제 적용 규격의 판본을 고정한다.[8][9][10][18]

4. 구조를 보는 눈은 네 개의 관계식에서 시작한다

‘큰 전압’, ‘큰 전류’, ‘긴 선’ 자체만으로 위험을 판정하지 않는다. 변화 속도, 결합 크기, 피해 회로의 임피던스를 붙여서 본다. 아래 관계식은 전기적으로 작은 구조와 약한 결합에서 첫 추정에 유용하다. 구조에 따른 공진·분포 효과가 지배하면 전송선 또는 전자기장 모델로 넘어간다.[2][3][4]

손으로 가늠하는 세 가지 크기

교육용 가정: 24V가 10ns에 변하고 결합 C가 1pF라면 변하는 구간의 결합 전류는 약 2.4mA다. 상호 인덕턴스 2nH에 10ns 동안 1A가 변하면 피해 루프의 유도 기전력은 약 0.2V다. 공유 인덕턴스 10nH에 같은 전류 변화가 흐르면 그 도체 양끝의 전압은 약 1V다.

이 값들은 LAN9354에서 측정된 값이 아니다. 특히 루프 전체의 기전력을 그대로 칩 핀 전압이라고 해석하면 안 된다. 종단과 병렬 경로를 포함해서 실제 피해 노드에 걸리는 몫을 구해야 한다. 이 추정의 가치는 “pF·nH라서 무시해도 된다”는 판단을 바로잡고, 정밀 해석할 경로를 좁히는 데 있다.

고주파를 의심하는 길이 기준

첫 경계는 구조의 최대 길이 D와 파장 λ의 비다. 공기 중 λ ≈ c/f이고, PCB에서는 유전체 때문에 파장이 더 짧다. 아래의 D/λ는 지름 0.30m인 구조를 공기 중에서 본 단순 계산이다.

D/λ가 커졌다는 것은 분포 효과를 봐야 한다는 신호다. 곧바로 고장하거나 특정 주파수에서 공진한다는 판정은 아니다. 20m 케이블도 길이 하나만으로 수신량이 결정되지 않으며 배치·종단·실드와 주변 금속이 관여한다.

5. 같은 외란인데 왜 한 구조만 차동 잡음이 생기는가

LearnEMC의 불균형 차이 모델은 전송 경로의 전기적 균형이 바뀌는 지점에 주목한다. 소개 자료는 정해진 모드 정의에서 VCM = VDM·Δh라는 관계를 설명한다. 이는 DM이 CM을 구동하는 관계이며, 그 식을 뒤집어 임의의 케이블 RF 전압이나 PHY 고장 전압을 계산해서는 안 된다. 내성 분석에서는 CM 자극에 대한 실제 종단의 DM 출력을 직접 구하는 편이 명료하다.[6]

대화형 예제: 두 입력으로의 결합이 다르면

같은 이상적인 외란원 Vs=1Vrms가 C₁·C₂를 거쳐 두 입력에 결합한다고 가정한다. 각 입력은 동일한 50Ω으로 기준 도체에 연결된다. C₁=2pF를 고정하고 C₂와 주파수를 바꾼다. 회로에는 다른 기생소자와 입력 사이의 직접 연결이 없다.

외란원 → C₁ → 입력 V₁ → 50Ω → 기준 도체

같은 외란원 → C₂ → 입력 V₂ → 50Ω → 같은 기준 도체

차동 잡음 |V₁−V₂| = 6.26 mV rms

Vᵢ / Vs = jωRCᵢ / (1 + jωRCᵢ)
VDM = V₁ − V₂

예상할 것: C₁=C₂이면 이 이상 모델의 차동 출력은 0이다. 결합 차이가 생기면 차동 잡음이 생긴다. 약한 결합 범위에서는 주파수·결합 차이에 거의 비례한다. 그러나 두 입력의 공통 전압은 0이 아니므로, 차동 잡음이 작다는 사실만으로 실제 입력 소자의 CM 허용 범위를 만족한다고 말할 수 없다.

이 예제는 LearnEMC의 용량성 결합 원리를 이용해 별도로 구성한 정확한 RC 회로 계산이다. openEMS 결과나 LAN9354 모델이 아니며, 50Ω도 Ethernet PHY의 실제 내부 종단이라는 가정이 아니다.[3]

실물에서는 한쪽 패드만 커지거나, 한 선만 24V 도체·함체에 가까워지거나, 한쪽 보호소자의 용량이 커지는 구조가 이런 차이를 만들 수 있다. 길이가 같아도 주변 구조와 종단이 다르면 외란 결합이 달라질 수 있다. 반대로 길이만 조금 다르다는 이유로 바로 EMC 고장이라고 판정하지도 않는다. 해당 대역에서 생기는 변환량을 본다.[19]

6. PALA720에 적용한 사전 설계 검토

검토 조건은 M12를 통한 약 20m 외부 케이블, Ethernet 두 쌍과 24V·0V, 적층 PCB, LAN9354, 금속 함체, 내부 모터 구동부다. 함체 접합부는 반지름 약 15cm, 틈은 1mm 미만이며 접합면은 아노다이징되어 있다는 현물 설명을 사용한다. 실드·기구·PCB 0V의 실제 RF 접촉 특성은 미확정이다. 금속의 정확한 재질도 이 설명만으로 확정하지 않는다.[20]

눈에 들어오는 구조첫 예측남길 모델설계 행동

부품에 근거한 관측점 선택: LAN9354 제조사 지침은 디지털 GND의 연속성을 권고하고, RBIAS 배선에 유도된 잡음이 시스템 고장을 일으킬 수 있음을 명시한다. 따라서 “GND가 칩에서 멀다”보다 입력·전원·바이어스와 그 로컬 기준 사이의 전압을 관측하는 것이 구체적이다.[13]

시뮬레이션으로 바로 얻을 결정: 같은 단자 외란에서 현재 접속부와 대칭을 개선한 접속부를 비교한다. 같은 내부 스위칭 자극에서 리턴 경로 변경 전후를 비교한다. 같은 RF에서 함체 접합 조건에 따라 민감 단자 결합이 얼마나 움직이는지 본다. 그 결과로 PCB 변경, 커넥터·실드 변경, 기구 접합 사양 중 먼저 손댈 대상을 정한다.

이미 확보한 SI 분석의 정확한 위치

ATLAS의 PCB 구간 분석에는 Gerber 도체·기준면·근사 적층 커넥터가 포함되지만, 실제 M12 몸체, 트랜스 내부, PHY 실리콘, 외부 케이블과 잡음원은 제외된 구간이 있다. 기존 차동 전달 분석은 유용한 출발점이며, CM 자극·기준전위·실장 종단을 추가하는 것이 다음 단계다. 기존 RL·IL로 EMC 내성을 판정하지 않는다.[20]

회전 중 접촉·피복 손상과 통신 오류의 연관성은 별도 현물 관찰이다. 접촉 단절이나 도체의 기계적 접촉은 정적 선형 RF 모델이 자동으로 찾는 고장이 아니다. PortA의 외부 케이블 경로와 PortB의 슬립링 경로도 분리한다. 이 구분은 EMC 분석의 범위를 좁혀 주며, 현재 고장을 모두 EMC로 확정한다는 뜻이 아니다.

7. 함체의 전기적 경로를 남기며 간소화하기

도체의 큰 배치와 전류 연결 관계는 남기고, 전기적으로 중요하지 않은 모양을 줄인다. LearnEMC는 RF 차폐에서 긴 접합부와 케이블 관통부를 강조하며, 겹침을 통해 접합 임피던스를 낮출 수 있다고 설명한다. 금속 두께만으로 전체 차폐를 대표하지 않는다.[5]

접합부 모델의 실행 순서

  1. 접합을 완전히 도통시킨 기준 모델: 해당 접합부의 누설을 제거한 참조값을 구한다. 실제 제품의 최악값은 아니다.
  2. 두 부품이 절연되어 겹치는 모델: 알려진 틈의 범위 안에서 공기·절연층·겹침을 표현한다. 우선 단순 형상으로 만든다.
  3. 격자가 과도하면 분포 등가소자로 교체: 작은 접합 구간의 결합 C와 접촉 R/L을 산출하거나 추정해 둘레 여러 위치에 배치한다. 구간 길이는 분석 대역에서 전기적으로 짧아야 한다. 낮은 주파수에서 얻은 하나의 C를 GHz까지 그대로 적용하지 않는다.

openEMS에는 방향을 지정한 집중 R·L·C 요소가 있다. 그러나 아노다이징 환형 접합부를 자동으로 검증해 주는 전용 기능이 확인된 것은 아니다. 분포 등가소자 방식은 별도 모델링 제안이다. 먼저 작은 접합 구간의 명시적 형상과 비교해 주파수 응답을 확인하고 사용한다.[16]

현재 주어진 반지름으로 둘레는 약 0.94m다. 이를 그대로 직선 슬롯 공식에 넣어 차폐 컷오프를 정하지 않는다. 1mm 미만이라는 틈 폭도 전체 접합부의 RF 성능을 하나의 숫자로 정해 주지 않는다. 겹침·전류 방향·접촉 상태가 함께 작용한다.

실제로 생략할 수 있는 경우

현실적으로 가능한 접합 조건을 바꾸어도 관심 단자의 결합량 변화가 작고 설계 여유가 크다면 접합부 상세 모델링을 뒤로 미룬다. 변화가 크면 나사 하나씩 재현하기에 앞서 접합의 전기적 사양을 정할 것인지, 그 차폐에 의존하지 않도록 회로를 강화할 것인지를 결정한다. 접합이 불명확한 상태에서 차폐 이득을 확정적으로 설계 예산에 넣지 않는다.

함체 없는 PCB가 항상 더 나쁜 조건은 아니다. 함체는 장과 귀환 경로를 바꾸고 특정 결합·공진을 만들 수 있다. 무함체 분석은 취약 회로 탐색의 기준 모델로 쓰고, 단순 함체 모델로 결과가 뒤집히는지 확인한다. 감쇠를 일률적으로 1/10로 두는 규칙도 사용하지 않는다.[5][14]

A. 커넥터에서 ‘압축한다’는 말의 정확한 뜻

20m 케이블을 하나의 점으로 없애는 대신 커넥터의 여러 도체에 대한 전압·전류와 임피던스 관계로 대체한다. 첫 단계는 표준화한 CM·DM 자극을 따로 넣는 선별 분석이다. 동시에 유입되는 상관관계까지 보려면 다도체 전송선·다중 포트 모델이 필요하다.

이 방식은 “커넥터에 이런 외란이 도달했을 때 보드가 어떻게 반응하는가”를 답한다. “어느 현장 RF가 실제 20m 케이블에서 이 전압을 만드는가”까지 답하려면 케이블 외부 수신 모델을 덧붙여야 한다. 모드의 정의를 고정한 후 Sdc를 CM 입력 → DM 출력으로 사용한다. Scd는 반대 방향의 변환이다. 포트 번호와 기준 임피던스도 함께 기록한다.

처음에는 전압 전달비를 직접 계산하는 편이 쉽다. 두 선에 동일 위상의 자극을 주고, 실제 입력 CM 전압과 출력 DM 전압을 측정한다. 100Ω 차동 종단 하나만 두면 CM 종단이 정의되지 않는다는 점에 주의한다. 트랜스·센터탭·기생 C·PHY측 종단을 관심 범위에 맞춰 포함한다.

B. 모터는 먼저 전기적 발생원으로 줄인다

모터 전체의 회전 전자기장을 먼저 풀지 않는다. 드라이버와 벅의 파형에서 고주파 전류 루프와 전압 노드를 정의하고, 그 부분의 결합을 구한다. kHz 기본파만 보는 것도 충분하지 않다. 에지의 상승시간과 링잉이 관련 대역을 확장할 수 있다. 저주파 공급 변동·자기 센서 응답은 회로·준정적 모델이 효율적이다.

C. 외부 RF의 구체적 구성

openEMS 공식 금속구 예제는 TFSF 평면파, 전파 방향, E 편파, 가우시안 자극과 PML을 제공한다. 이를 PCB·함체의 기하로 바꾸고 필요한 종단을 추가한다. 전압·전류·E·H 프로브도 제공된다.[15][17]

  1. 물체와 대표 도체를 TFSF 경계 안에 두고, 그 바깥 균질 영역과 PML을 마련한다.
  2. ±X·±Y·±Z 방향과 각 방향의 직교 선형 편파 두 개로 시작한다. 이 12조건은 설계 선별용 제안이며 IEC의 보편적 규정이나 전 방향 최악값 보장은 아니다.
  3. 가우시안 광대역 자극의 입사 스펙트럼으로 출력 스펙트럼을 나눈다. 코드의 E 방향 벡터 크기만 보고 모든 주파수에 1V/m가 입사했다고 처리하지 않는다.
  4. 위험 후보 대역에서 주파수 해상도·관측 시간·각도를 보강한다. 선형 모델이면 두 편파의 복소 응답으로 같은 입사 방향의 다른 선형 편파를 합성할 수 있다. 진폭만 저장하면 이 정보를 잃는다.

첫 구현은 80MHz–1GHz에서 정상 동작을 확인하고, 이어 1–3GHz·3–6GHz처럼 나누어 최대 주파수에 맞는 격자를 사용한다. 낮은 대역의 통과로 높은 대역을 생략하지 않는다. 세 대역을 나누는 방식은 실행 효율을 위한 제안이다.

ESD·EFT·서지를 같은 RF 계산으로 끝내지 않는다

선형 수동 구조의 전달함수는 외란 펄스가 어떤 경로로 전달되는지 계산하는 데 사용할 수 있다. 그러나 TVS 클램핑, 트랜스 포화, 절연 파괴, IC 오동작을 보려면 해당 비선형·동작 모델이 필요하다. openEMS의 역할은 경로의 기생 성분과 선형 결합을 얻는 것으로 두고, 보호소자·전원 응답은 SPICE 계열 해석과 연결한다. 150kHz에서 ms 단위 전원 변동까지 미세 격자 FDTD 한 번으로 처리하지 않는다.

ESD가 함체에 닿는 경우에도 주입점뿐 아니라 방전 전류의 귀환 경로를 포함해야 한다. Ethernet 제조사 자료는 접지로의 방전이 CM 잡음과 링크 다운으로 이어질 수 있음을 다룬다. 큰 금속 함체라는 이유로 이 경로를 제거하지 않는다.[11][18]

9. 결과를 설계 결정으로 연결하기

서로 단위가 다른 10V/m RF와 1A 루프 전류를 그대로 비교해서 큰 노이즈를 고를 수는 없다. 동일한 피해 회로의 허용 여유로 환산한다. 입력이 서로 다르면 각 외란에 대한 전달함수를 따로 사용한다.

예상 피해량 N(f,θ) = |T(f,θ)·S(f)|
여유 M = 20log₁₀[Vallow / Nmax]

S는 정의한 외란, T는 그 외란에서 관측점으로의 전달함수, θ는 접합·종단·배치 등 가정이다. N과 Vallow는 같은 물리량·대역·진폭 기준이어야 한다. 과도 펄스의 최대값은 주파수별 진폭만 곱한 최대값으로 대신하지 않고 위상을 포함해 시간 응답을 복원한다.

확인된 상태내릴 판단다음 행동
알려진 기능 허용치를 초과하고 모델 변화에도 유지설계 수정 대상지배적인 결합 경로를 줄이는 변경을 선택
허용치 아래이며 외란·가정·수치 오차를 고려한 여유가 충분해당 범위에서는 후순위추가 미세 모델링을 멈추고 다른 경로로 이동
특정 가정에서만 크거나 개선안 순위가 바뀜민감한 가정이 설계 결정 요인그 값만 확보하거나, 그 값에 덜 의존하는 구조로 변경
PHY의 해당 주파수·파형 허용치가 없음취약 후보와 상대 개선량까지 판정실제 동작 중 주입 시험으로 기능 한계 확보. 임의 mV로 합격선을 만들지 않음

교육용 판단 예: 어떤 회로의 검증된 허용 잡음이 100mV이고, 정의한 외란·가정에서 계산된 최대 잡음이 10mV라면 명목 여유는 20dB다. 별도로 근거 있게 정한 전체 불확실성·예비 여유가 6dB라면 남는 여유는 14dB다. 여기서 100mV와 6dB는 예시 값이며 LAN9354의 한계나 EMC 업계 공통 규칙이 아니다.

보수적 판단·수치 안정성·완제품 판정의 상세 조건

‘보수적’이라고 부를 수 있는 것과 없는 것

방법성립 조건과 의미
외란 진폭을 높임동일한 선형 모델·파형·주파수에서는 출력도 비례 증가. 명확한 진폭 여유를 둘 수 있음
여러 선형 경로의 크기를 합산각 복소 응답의 절댓값 합은 포함한 경로 합의 상한. 위상 취소에 기대지 않는 평가가 가능
가정값 몇 개를 바꿔 최대값 선택그 표본 집합의 최대값. 내부 공진이나 미탐색 조건까지 포함한 상한은 아님
틈을 키움·함체를 제거함·PEC를 사용함항상 나쁜 방향이라는 보장이 없음. 결합·공진·손실 변화의 효과를 확인해야 함

‘오류를 놓치지 않는 근사’의 핵심은 형상을 거칠게 만드는 데 있지 않다. 외란과 귀환 경로를 유지하고, 불확실한 변수가 판정을 뒤집는지 확인하며, 허용 여유보다 큰 모델 오차를 숨기지 않는 데 있다.

계산을 믿기 위한 최소 확인

  1. 기본 원리: 대칭 RC·루프 등 답의 방향을 아는 작은 모델에서 단위·부호·포트·정규화를 확인한다.
  2. 수치 안정성: 중요한 대역에서 격자를 한 번 개선하고, PML 거리 또는 관측 시간을 바꿔 결론이 유지되는지 확인한다. 좁은 공진을 광대역의 성긴 샘플로 놓치지 않는다.
  3. 결정의 안정성: 접합·소스·종단의 현실적인 범위를 바꿔 비교한다. 예를 들어 1dB 안팎으로 계산값이 움직이는데 두 설계 차이가 0.5dB라면 우열을 확정하지 않는다.

통신 제품의 마지막 판정

완제품에서는 링크 다운, PHY 리셋, 심볼 오류·패킷 누락, 복구 시간과 데이터 유효성을 동작 조건에 맞춰 본다. PALA720의 설계 목표는 연속 RF 중 링크 다운·리셋이 없도록 두고, 과도 외란의 데이터 공백 허용치는 상위 시스템의 허용 시간으로 정하는 것이 타당하다. 이는 제품 적용 제안이다. 부품 Absolute Maximum은 정상 통신의 RF 허용치가 아니다.

Würth의 Ethernet 시험 자료도 EFT 중 잠시 정지했다가 복구하는 동작이 부품의 평가 기준을 만족해도, 상위 시스템에서는 정지로 이어질 수 있음을 지적한다. 시험 통과 조건과 크레인 시스템의 연속 동작 요구를 함께 정의해야 한다.[12]

실측으로 확인된 구조의 영향: 같은 자료의 통합 Ethernet 잭 설계에서는 두 10nF를 이용한 실드 접속 조건에서 EFT의 기능 유지 기준 A를 1kV까지, 직접 도통 접속 조건에서는 2kV까지 만족했다. 이 숫자는 그 시험 장치의 결과다. 전달 신호가 같은 기능을 하더라도, 실드 접속과 외란 귀환 경로가 내성에 차이를 만든다는 근거로 읽어야 한다. PALA720의 보장값이나 특정 커패시터 값의 보편적 처방으로 사용하지 않는다.[12]

10. 예측하는 눈을 기르는 다섯 번의 실험

각 실험은 실행 전에 예상 방향을 한 문장으로 적는다. 결과가 다르면 더 복잡한 그림을 만들기 전에 가정한 발생원·귀환 경로·관측량 중 무엇이 달랐는지 확인한다. 아래는 자료에 근거해 구성한 학습 순서이며 특정 강의의 목차를 그대로 옮긴 것은 아니다.

실험먼저 할 예측최소 모델과 관측량센서에 연결되는 부분
1. 용량성 결합약한 결합에서 C 또는 주파수가 증가하면 피해 전압 증가위 RC 계산 → 도체 두 개와 기준면. Vvictim/Vsource벅 노드·24V 도체와 민감 입력의 근접
2. 루프 결합공유 자속·dI/dt가 증가하면 유도 기전력 증가두 루프와 종단. Vvictim/Isource구동부·적층 커넥터·리턴 배치
3. 차동쌍의 비대칭같은 CM 자극에서도 한쪽 환경이 달라지면 DM 출력 변화실제 배선의 대칭안·비대칭안. CM→DM 전달과 CM 입력 임피던스M12→적층 PCB→트랜스 경계
4. 차폐와 접합접합 상태에 민감한 대역·편파가 존재할 수 있음단순 상자·피해 루프·접합. V/E와 표면 전류아노다이징된 환형 접합부
5. 실제 경로 비교선택한 구조 개선이 여러 외란 조건에서도 피해량 감소센서의 A/B/C 모델, 동일 입력·종단·관측점PCB 수정과 기구·배선 수정의 우선순위

첫 설계 검토에서 남길 한 장

각 후보마다 발생원 / 입력 조건 / 결합 경로 / 피해 노드 / 허용 여유 / 생략한 것 / 생략 근거 / 확인할 출력을 한 줄로 기록한다. 숫자가 미확정이면 먼저 전달함수를 구하고, 미확정 입력을 확정값처럼 넣지 않는다.

예: “M12 신호 도체의 CM 외란 → 접속부의 비대칭 → RX DM. 입력은 단자 1V로 정규화. 20m 외부 수신 과정은 모델 밖. 현재 구조와 대칭 개선안을 동일 종단에서 비교. PHY 기능 한계 확보 전에는 합격 대신 변환량 감소와 취약 대역을 보고한다.”

이 단계의 성공은 실제 고장 주파수와 소수점까지 일치하는 것이 아니다. 구조를 보고 세운 가설이 계산에서 확인되고, 원인을 바꿨을 때 예상한 방향으로 움직이며, 그 판단이 모델의 작은 변화에도 유지되는 것이다. 허용 입력·허용 출력까지 확보하면 그 위에 설계 여유 판정을 올릴 수 있다.

11. 먼저 읽을 자료와 얻어야 할 것

1. LearnEMC — Introduction to EMC

‘Elements of an EMC Problem’부터 읽는다. 발생원·경로·피해 회로를 한 문장으로 적는 습관을 만든다. 시험 이름의 목록을 만드는 데서 멈추지 않는다. 원문 읽기

2. LearnEMC — Common Impedance / Electric Field / Magnetic Field Coupling

세 장의 관계식을 손으로 계산한다. 무엇을 생략했는지, 그 생략이 가능한 임피던스 조건이 무엇인지 확인한다. 특히 자기장 장의 추정값·정확값 비교가 이번 학습 목표와 직접 맞는다. 공유 경로 · 전기장 · 자기장

3. LearnEMC — Introduction to Imbalance Difference Modeling

‘Point #2’와 ‘IDM for simple worst-case analysis’, ‘intuitive EMC design guidance’를 우선 읽는다. 복잡한 케이블을 간단하게 다루는 근거와, 특정 배치 하나의 결과에 의존하지 않는 설계 관점을 얻는다. 원문 읽기

4. LearnEMC — Practical EM Shielding

‘Shielded Enclosures → Seams → Cable Penetrations’를 읽는다. 표면 전류가 접합부와 관통부에서 어떻게 이어지는지를 본다. 저주파 자기장 차폐는 별도의 절로 구분해 읽는다. 원문 읽기

5. Würth ANP116b + TI SNLA466A + LAN9354 지침

Würth의 §4.9–4.11로 실제 RF·EFT·서지의 결과가 어떻게 달라지는지 본다. TI의 §4는 Ethernet 링크 실패의 경로를 보강한다. 구체적인 회로 처방은 LAN9354 지침과 대조한다. 다른 PHY의 센터탭·GND·보호 부품 값을 그대로 복사하지 않는다. Würth 시험 · TI 분석 · LAN9354

자료 간의 적용 경계: LearnEMC의 차폐 접속 원칙은 금속 함체를 가로지르는 외란 전류의 처리에 초점을 둔다. PHY 문서는 신호 기준면·절연·전원 구성도 함께 다룬다. ‘실드를 함체에 짧게 연결’과 ‘디지털 GND를 아무 곳에서나 함체에 합침’은 같은 처방이 아니다. 연결하는 두 도체가 무엇인지 먼저 구별하면 상반돼 보이는 권고를 해석하기 쉬워진다.

공개 웹 교재와 제조사의 원문을 중심으로 선정했다. 유료 강의 전체를 열람했다거나 접근하지 못한 영상의 내용을 확인한 것으로 취급하지 않는다.
