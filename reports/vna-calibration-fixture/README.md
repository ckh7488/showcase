# CM 프로브 교정지그 · A03

ATLAS의 독립 보고서다. CM/RF 전류 프로브의 전달 임피던스를 교정하는 A03를 다룬다. 이더넷 발룬/커넥터 지그는 별도 `ethernet-vna-fixture` 보고서이며 교정 데이터를 공유하지 않는다.

## 내용과 상호작용

- 실제 A03 PCB에서 추출한 앞/뒤 동박, 외곽·두 창·홀. SIG/GND 강조, 중앙 확대, 전체 복귀.
- SOLT → 빈 지그 → 헤드 장착 through → 프로브 전달 → 외장 로드 반사 연결 전환. 점선은 자기 결합이며 전선이 아니다.
- 지그 한 대의 전용 BOM 4행과 공용 측정 준비물. 통합 RF BOM에서 분리해 표시한 설치 수량으로 추가 구매량이 아니다.
- 실제 저장된 100/300/500 MHz 결과 선택. 9개 빈 지그 모델의 최소/최대만 표시하며 보간·재시뮬레이션하지 않는다.

`board-data.js`는 native PCB 좌표, `board-source.json`은 추출 근거다. 뒷면도 앞에서 투시한 좌표다. 코어 위치 점선은 설명용이며 코어 CAD/체결 공간을 나타내지 않는다. 제조 원본을 대체하지 않는다.

`results.json`과 `results.js`는 동일 데이터의 내려받기/오프라인 표시본이다. 원본 A03 케이스만 사용한다. `bom.json`의 `quantity_per_fixture`가 지그 한 대의 수량이며 `bom.csv`와 HTML 표를 함께 유지한다. `sources.json`의 상대 원본명·해시는 내부 검토 근거를 식별하며 개인 경로를 노출하지 않는다.

## 유지 관리

교정 근거는 백서 Rev.A/0.7의 11.6과 DEC-053이다. 동시 진행된 DEC-055 변경 원문을 대조해 벤치 절차 초안·권선 자기공진 사전 기록·교정 범위와 진단 등급 구분을 반영했다. 실측 교정 데이터와 출력 기준 자동 환산, 시간 파형 역보정은 아직 없다. 1–500 MHz 수행 범위를 실측 완료 정확도나 프로브 평탄 대역으로 바꾸지 않는다.

보고서 등록은 루트 `reports.json`의 `vna-calibration-fixture` 한 항목으로 한다. CM 프로브 표지에는 링크만 두고, 이번 독립 페이지 생성 때문에 RF 원본이나 제조 파일을 변경하지 않는다. RF 문서를 다시 로컬 내보낸 뒤에는 루트에서 다음 명령으로 표지의 교차 링크를 복구한다.

```sh
python scripts/link_vna_fixture.py
python scripts/validate.py
```

브라우저에서는 목록 → 보고서 → 목록, PCB 층/신호/확대, 5개 연결 단계, 3개 주파수/3개 지표, BOM 내려받기, 1280/390/320 px 화면을 확인한다. 정적 검사·브라우저 검사는 RF 실측이 아니다. GitHub Pages 공개는 별도 배포 결과와 실제 주소를 확인한 뒤 보고한다.
